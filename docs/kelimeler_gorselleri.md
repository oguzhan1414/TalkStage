# Kelimeler bölümü: yeni görseller

Yön: krem zemin, kâğıt kartlar, koyu lacivert mürekkep düğmeler. Renkler kelime türlerinden gelir (kelime resimlerindeki dairelerle aynı): isim nane yeşili, fiil mercan, sıfat güneş sarısı, zarf açık gök mavisi. Mor yalnızca Mivo'nun ceketinde kalır.

| Rol | Renk |

| Zemin | krem `#FBF7F1` |
| Kart | beyaz `#FFFFFF`, çerçeve `#EDE7DD` |

## Stil bloğu (her promptun sonuna ekle)

```
Flat 2D vector illustration in exactly the same style as the attached reference character sheet: geometric rounded shapes, flat fills with one soft shadow tone, no outlines, big expressive eyes, stylised but not chibi. Colour palette: warm cream, deep ink navy #1F2A44, mint green #6CC4A1, coral #F2836B, sunny yellow #F4C152, soft sky blue #8EC5E8, a touch of gold #E8A93B. No purple or violet anywhere except Mivo's indigo bomber jacket. Transparent background. No text, no letters, no numbers, no logos, no frame, no border.
```
