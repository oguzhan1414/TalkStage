## [A1_G01] Subject Pronouns & Verb To Be (Am / Is / Are)

**Kısaca ne işe yarar:** Kim olduğumuzu, mesleğimizi, yaşımızı, milliyetimizi, nerede bulunduğumuzu ve anlık/genel durumlarımızı (açlık, yorgunluk, mutluluk, hava durumu vb.) ifade etmek için kullanılan temel durum bildirme yapısıdır.

**Görsel Şema / Zihin Haritası (Visual Mind-Map):**

```
                    ┌─────────────────────────┐
                    │    VERB TO BE (Olmak)   │
                    └────────────┬────────────┘
                                 │
         ┌───────────────────────┼───────────────────────┐
         ▼                       ▼                       ▼
   ┌───────────┐           ┌───────────┐           ┌───────────┐
   │     AM    │           │     IS    │           │    ARE    │
   └─────┬─────┘           └─────┬─────┘           └─────┬─────┘
         │                       │                       │
   ┌─────▼─────┐     ┌───────────▼───────────┐     ┌─────▼─────┐
   │     I     │     │     HE / SHE / IT     │     │ YOU/WE/THEY│
   │  (Ben)    │     │      (O - Tekil)      │     │(Sen/Biz/On)│
   └───────────┘     └───────────────────────┘     └───────────┘
                                 │
                   ┌─────────────┴─────────────┐
                   ▼                           ▼
        [Meslek / Kimlik]               [Duygu / Durum / Konum]
        "I am a developer."             "The server is ready."
        "She is an engineer."           "We are in the office."
```

**Kural / Yapı Tablosu:**

| Özne Grubu | Olumlu (+) | Olumsuz (-) | Soru (?) | Kısa Cevaplar |
|:---|:---|:---|:---|:---|
| **I** | `I am` (`I'm`) | `I am not` (`I'm not`) | `Am I...?` | *Yes, you are. / No, you aren't.* |
| **He / She / It** | `He is` (`He's`) | `He is not` (`He isn't`) | `Is he...?` | *Yes, he is. / No, he isn't.* |
| **You / We / They** | `They are` (`They're`) | `They are not` (`They aren't`) | `Are they...?` | *Yes, they are. / No, they aren't.* |

* **Cümle Formülü:** `[Özne] + [am / is / are] + [İsim / Sıfat / Yer Edatı]`

**Detaylı Anlatım:** İngilizcede her cümlenin bir fiile ihtiyacı vardır. Ancak Türkçede "Ben yazılımcıyım" ya da "Hava çok sıcak" derken fiziksel bir eylem (koşmak, yazmak vb.) kullanmayız; cümleyi ek-fiille bitiririz. İngilizcede bu ek-fiil görevini **Verb To Be (am, is, are)** üstlenir.

'To be' üç ana işlev için kullanılır:

1. **Kimlik & Meslek:** *I am Oğuzhan.* / *She is a UX designer.*  
2. **Nitelik & Durum:** *The code is clean.* / *They are excited.*  
3. **Konum & Yer:** *The team is in London.* / *The database is on the cloud.*

Soru yaparken `am/is/are` öznenin önüne geçer. Soru kelimeleri (Wh- questions: What, Where, Who, How) varsa en başa gelir: *"Where is the server?"*

**Canlı Mini Diyalog (Real-Life Scenario):**

> **Alex:** Hello\! Are you the new mobile developer for our project?  
> **Oğuzhan:** Yes, I am. I'm very happy to join the team.  
> **Alex:** Welcome\! Is your development environment ready on your laptop?  
> **Oğuzhan:** No, it isn't ready yet, but the installation files are on my desktop.

**Sık Yapılan Hatalar:**

* ❌ *Hatalı:* I am work at a tech company.  
  ✔️ *Doğru:* **I work at a tech company.** *(Açıklama: Cümlede 'work' eylem fiili varken 'am' kullanılmaz).*  
* ❌ *Hatalı:* She very smart and friendly.  
  ✔️ *Doğru:* **She is very smart and friendly.** *(Açıklama: 'To be' fiili cümleden atılamaz).*  
* ❌ *Hatalı:* They is in the meeting room.  
  ✔️ *Doğru:* **They are in the meeting room.** *(Açıklama: Çoğul özneler 'are' alır).*

**Genişletilmiş Örnek Cümleler:**

1. 🇬🇧 *I am a full-stack software engineer.* → 🇹🇷 Ben bir tam yığın (full-stack) yazılım mühendisiyim.  
2. 🇬🇧 *The production server is currently active and stable.* → 🇹🇷 Canlı sunucu şu anda aktif ve kararlıdır.  
3. 🇬🇧 *We are not ready for the final client demo yet.* → 🇹🇷 Henüz nihai müşteri demosu için hazır değiliz.  
4. 🇬🇧 *Is this database connection encrypted?* → 🇹🇷 Bu veritabanı bağlantısı şifrelenmiş mi?  
5. 🇬🇧 *Are you available for a quick five-minute sync call?* → 🇹🇷 Beş dakikalık hızlı bir durum görüşmesi için müsait misiniz?  
6. 🇬🇧 *They are very experienced in cloud infrastructure.* → 🇹🇷 Onlar bulut altyapısı konusunda oldukça deneyimlidirler.  
7. 🇬🇧 *It is not a critical error, just a minor warning.* → 🇹🇷 Bu kritik bir hata değil, yalnızca küçük bir uyarıdır.  
8. 🇬🇧 *Where are the API configuration files located?* → 🇹🇷 API yapılandırma dosyaları nerede bulunmaktadır?  
9. 🇬🇧 *She is the lead product manager for this application.* → 🇹🇷 O, bu uygulamanın baş ürün yöneticisidir.  
10. 🇬🇧 *Why is the network latency so high today?* → 🇹🇷 Bugün ağ gecikmesi neden bu kadar yüksek?

## [A1_G02] Articles (A, An, The) & Demonstratives (This, That, These, Those)

**Kısaca ne işe yarar:** İsimlerin belirli (bilinen) mi yoksa genel (herhangi bir) mi olduğunu tayin eder; nesnelerin konuşucuya olan yakınlık ve uzaklık ilişkisini belirtir.

**Görsel Şema / Zihin Haritası (Visual Mind-Map):**

```
                ┌──────────────────────────────────────────────┐
                │          DEMONSTRATIVES (Mesafe Matrisi)      │
                └──────────────────────┬───────────────────────┘
                                       │
                      ┌────────────────┴────────────────┐
                      ▼                                 ▼
             [ YAKIN (Near) ]                   [ UZAK (Far) ]
      ┌───────────────────────────────┐  ┌───────────────────────────────┐
Tekil │  👉 THIS  ("Bu laptop")       │  │  👉 THAT  ("Şu sunucu")       │
      ├───────────────────────────────┤  ├───────────────────────────────┤
Çoğul │  👉 THESE ("Bu dosyalar")     │  │  👉 THOSE ("Şu kablolar")     │
      └───────────────────────────────┘  └───────────────────────────────┘

                ┌──────────────────────────────────────────────┐
                │          ARTICLES (Tanımlık Hiyerarşisi)     │
                └──────────────────────┬───────────────────────┘
                                       │
                ┌──────────────────────┴──────────────────────┐
                ▼                                             ▼
       [ A / AN (Belirsiz) ]                         [ THE (Belirli/Bilinen) ]
  • Herhangi bir tekil isim                     • Hem konuşan hem dinleyen bilir
  • a + Sessiz SES: a developer, a user         • the database, the sun, the API
  • an + Sesli SES: an error, an hour           • Daha önce bahsedilmiş nesneler
```

**Kural / Yapı Tablosu:**

| Belirteç | Kullanım Kuralı | Örnek Kelimeler | Cümle İçi Kullanımı |
|:---|:---|:---|:---|
| **A** | Sessiz harf *sesiyle* başlayan tekil sayılan isimler | *a book, a system, a university* (/j/ sesi) | *I need a new monitor.* |
| **An** | Sesli harf *sesiyle* başlayan tekil sayılan isimler | *an app, an issue, an hour* (/aʊ/ sesi) | *We found an unexpected bug.* |
| **The** | Bilinen, tanımlı, tek olan veya daha önce anılan isimler | *the internet, the team, the code* | *I fixed the bug we discussed.* |
| **This / That** | Tekil isimler (Yakın: This / Uzak: That) | *this project / that server* | *This is my desk, that is yours.* |
| **These / Those** | Çoğul isimler (Yakın: These / Uzak: Those) | *these tests / those computers* | *These logs show the error.* |

**Detaylı Anlatım:** *A* ve *An* arasındaki ayrım harfe değil, **çıkardığı sese (fonetiğe)** dayanır. "Hour" kelimesi sessiz 'h' ile yazılsa da sesli /aʊ/ sesiyle okunduğu için *an hour* olur. "University" kelimesi sesli 'u' ile başlasa da yarı-sessiz /j/ (y) sesiyle okunduğu için *a university* olur.

*The* belirteci dinleyiciye şu mesajı verir: *"Sen de hangi şeyden bahsettiğimi tam olarak biliyorsun."*

- *"I bought a computer."* (Herhangi bir bilgisayar aldım \- ilk kez bahsediyorum).  
- *"The computer is fast."* (Bahsettiğim, az önce aldığım o bilgisayar hızlı).

**Canlı Mini Diyalog (Real-Life Scenario):**

> **Sarah:** Can you pass me **that** hard drive on the table over there?  
> **David:** Do you mean **this** black hard drive right here?  
> **Sarah:** Yes, exactly. I need to backup **the** database files before the update.  
> **David:** Great. It has **an** ultra-fast USB-C connection, so it will be quick.

**Sık Yapılan Hatalar:**

* ❌ *Hatalı:* I waited for an university bus for a hour.  
  ✔️ *Doğru:* **I waited for a university bus for an hour.** *(Açıklama: University sessiz 'y' sesiyle, hour ise sesli 'o' sesiyle başlar).*  
* ❌ *Hatalı:* We are developing a new mobile applications.  
  ✔️ *Doğru:* **We are developing a new mobile application.** *(Açıklama: 'a/an' çoğul isimlerle kullanılamaz).*  
* ❌ *Hatalı:* The programming is a good career.  
  ✔️ *Doğru:* **Programming is a good career.** *(Açıklama: Genel kavramların önüne gereksiz 'the' konmaz).*

**Genişletilmiş Örnek Cümleler:**

1. 🇬🇧 *This is an urgent security issue in the payment gateway.* → 🇹🇷 Bu, ödeme ağ geçidindeki acil bir güvenlik sorunudur.  
2. 🇬🇧 *Can you see that red indicator light on the server rack?* → 🇹🇷 Sunucu kabinindeki şu kırmızı uyarı ışığını görebiliyor musun?  
3. 🇬🇧 *These unit tests verify the authentication module.* → 🇹🇷 Bu birim testleri kimlik doğrulama modülünü doğrular.  
4. 🇬🇧 *Those computers in lab 4 are reserved for the AI workshop.* → 🇹🇷 4 numaralı laboratuvardaki şu bilgisayarlar yapay zeka atölyesi için ayrılmıştır.  
5. 🇬🇧 *The customer sent an email regarding the subscription pricing.* → 🇹🇷 Müşteri, abonelik fiyatlandırmasına ilişkin bir e-posta gönderdi.  
6. 🇬🇧 *We need a fast and reliable caching mechanism.* → 🇹🇷 Hızlı ve güvenilir bir önbellekleme mekanizmasına ihtiyacımız var.  
7. 🇬🇧 *The sun rises in the east.* → 🇹🇷 Güneş doğudan doğar (Dünyada tek olduğu için 'the').  
8. 🇬🇧 *This framework is easier to learn than that one.* → 🇹🇷 Bu çatı (framework), şuna kıyasla öğrenmesi daha kolaydır.  
9. 🇬🇧 *Is there an open-source alternative to this software?* → 🇹🇷 Bu yazılıma açık kaynaklı bir alternatif var mı?  
10. 🇬🇧 *These are the official guidelines for the visa interview.* → 🇹🇷 Bunlar vize mülakatı için resmi yönergelerdir.

## [A1_G03] Possessive Adjectives & Possessive 's

**Kısaca ne işe yarar:** Bir nesnenin, projenin, görevin veya durumun kime/neye ait olduğunu ve kişi-nesne arasındaki aidiyeti ifade etmek için kullanılır.

**Görsel Şema / Zihin Haritası (Visual Mind-Map):**

```
             ÖZNE (Subject)             İYELİK SIFATI (Possessive Adj)
             ──────────────             ─────────────────────────────
                  I             ───►              MY      (Benim)
                 YOU            ───►             YOUR     (Senin/Sizin)
                  HE            ───►              HIS     (Onun - Erkek)
                 SHE            ───►              HER     (Onun - Kadın)
                  IT            ───►              ITS     (Onun - Cansız/Hayvan)
                  WE            ───►              OUR     (Bizim)
                 THEY           ───►             THEIR    (Onların)

                                KESME İŞARETİ ('s) KURALI
                                ─────────────────────────
             [Tekil İsim]  ──►  Oğuzhan's laptop   (Oğuzhan'ın dizüstü bilgisayarı)
             [Düzenli Çoğul] ──►  The students' app   (Öğrencilerin uygulaması)
             [Düzensiz Çoğul]─► The children's toys (Çocukların oyuncakları)
```

**Kural / Yapı Tablosu:**

| Zamir / İsim | İyelik Yapısı | Formül & Örnek | Türkçe Anlamı |
|:---|:---|:---|:---|
| **I** | `my` | `my + Noun` → *my repository* | benim depom |
| **You** | `your` | `your + Noun` → *your account* | senin/sizin hesabınız |
| **He** | `his` | `his + Noun` → *his commit* | onun (erkek) işlemesi |
| **She** | `her` | `her + Noun` → *her presentation* | onun (kadın) sunumu |
| **It** | `its` | `its + Noun` → *its configuration* | onun (nesne) yapılandırması |
| **We** | `our` | `our + Noun` → *our roadmap* | bizim yol haritamız |
| **They** | `their` | `their + Noun` → *their server* | onların sunucusu |
| **Tekil İsim** | `Noun + 's` | `Developer's role` | geliştiricinin rolü |
| **-s ile biten Çoğul** | `Noun + '` | `Engineers' meeting` | mühendislerin toplantısı |

**Detaylı Anlatım:** İyelik sıfatları (`my, your, his, her, its, our, their`) **asla tek başlarına kullanılamazlar**; arkalarından mutlaka bir isim gelmek zorundadır (*"This is my laptop"*).

Üçüncü tekil şahıslarda cinsiyet ayrımına dikkat edilmelidir:

- Erkek için: *his* (*His name is John.*)  
- Kadın için: *her* (*Her name is Sarah.*)  
- Cansız nesne / yazılım / şirket için: *its* (*The system updated its cache.*)

*Önemli Fark: It's vs. Its:*

- `It's`: *"It is"* veya *"It has"* ifadesinin kısaltmasıdır (Örn: *It's cold today.*).  
- `Its`: Sahiplik sıfatıdır, kesme işareti almaz (Örn: *The app changed its design.*).

**Canlı Mini Diyalog (Real-Life Scenario):**

> **Manager:** Where is **Oğuzhan's** latest progress report?  
> **Developer:** It is in **our** shared Google Drive folder. **His** code updates are also merged.  
> **Manager:** Excellent. Did **the company's** client approve **their** proposal?  
> **Developer:** Yes, **her** feedback was very positive.

**Sık Yapılan Hatalar:**

* ❌ *Hatalı:* The company updated it's privacy policy.  
  ✔️ *Doğru:* **The company updated its privacy policy.** *(Açıklama: Sahiplik anlamındaki 'its' kesme işareti almaz).*  
* ❌ *Hatalı:* My sister is a developer. His code is very clean.  
  ✔️ *Doğru:* **My sister is a developer. Her code is very clean.** *(Açıklama: Kadın özne için 'her' kullanılır).*  
* ❌ *Hatalı:* This is my.  
  ✔️ *Doğru:* **This is my project.** veya **This is mine.** *(Açıklama: İyelik sıfatından sonra isim gelmelidir).*

**Genişletilmiş Örnek Cümleler:**

1. 🇬🇧 *Our team's primary objective is horizontal scalability.* → 🇹🇷 Ekibimizin birincil hedefi yatay ölçeklenebilirliktir.  
2. 🇬🇧 *Her pull request was reviewed and merged into main.* → 🇹🇷 Onun çekme isteği (PR) incelendi ve ana dala birleştirildi.  
3. 🇬🇧 *The mobile app stores its session tokens securely in local storage.* → 🇹🇷 Mobil uygulama, oturum belirteçlerini yerel depolamada güvenli şekilde saklar.  
4. 🇬🇧 *Is that your final architecture proposal for the client?* → 🇹🇷 Bu, müşteri için hazırladığınız nihai mimari teklifiniz mi?  
5. 🇬🇧 *The developers' workstations are equipped with high-end GPUs.* → 🇹🇷 Geliştiricilerin iş istasyonları üst düzey GPU'larla donatılmıştır.  
6. 🇬🇧 *His brother specializes in 3D modeling and additive manufacturing.* → 🇹🇷 Onun erkek kardeşi 3D modelleme ve katmanlı üretim alanında uzmanlaşmıştır.  
7. 🇬🇧 *Their cloud infrastructure runs on Kubernetes clusters.* → 🇹🇷 Onların bulut altyapısı Kubernetes kümeleri üzerinde çalışmaktadır.  
8. 🇬🇧 *What is the database's default timeout duration?* → 🇹🇷 Veritabanının varsayılan zaman aşımı süresi nedir?  
9. 🇬🇧 *My cousin and I are developing an embedded defense system prototype.* → 🇹🇷 Kuzenim ve ben gömülü bir savunma sistemi prototipi geliştiriyoruz.  
10. 🇬🇧 *Please enter your username and its associated password.* → 🇹🇷 Lütfen kullanıcı adınızı ve onunla ilişkili şifreyi giriniz.

## [A1_G04] Present Simple Tense (Geniş Zaman)

**Kısaca ne işe yarar:** Günlük rutinleri, alışkanlıkları, genel doğruları (bilimsel/doğa yasaları) ve kalıcı durumları anlatmak için kullanılan ana zaman yapısıdır.

**Görsel Şema / Zihin Haritası (Visual Mind-Map):**

```
                  ┌──────────────────────────────────────────────┐
                  │          PRESENT SIMPLE DÖNGÜSÜ              │
                  │       (Rutinler & Genel Doğrular)            │
                  └──────────────────────┬───────────────────────┘
                                         │
        ┌────────────────────────────────┴────────────────────────────────┐
        ▼                                                                 ▼
[ I / YOU / WE / THEY ]                                         [ HE / SHE / IT ]
───────────────────────                                         ─────────────────
(+) I code every day.                                           (+) He codeS every day.
(-) I do NOT code. (don't)                                      (-) He does NOT code. (doesn't)
(?) DO you code?                                                (?) DOES he code?
(Fiil her zaman YALIN kalır)                                    (Olumlu cümlede -s/-es/-ies eklenir,
                                                                 olumsuz ve soruda fiil YALIN kalır!)
```

**Kural / Yapı Tablosu:**

| Cümle Türü | I / You / We / They | He / She / It |
|:---|:---|:---|
| **Olumlu (+)** | `Özne + V1` (*I test the code.*) | `Özne + V1(-s/-es/-ies)` (*He tests the code.*) |
| **Olumsuz (-)** | `Özne + don't + V1` (*We don't deploy.*) | `Özne + doesn't + V1` (*She doesn't deploy.*) |
| **Soru (?)** | `Do + Özne + V1?` (*Do you write tests?*) | `Does + Özne + V1?` (*Does he write tests?*) |
| **Kısa Cevap** | *Yes, I do. / No, we don't.* | *Yes, she does. / No, he doesn't.* |

* **3\. Tekil Şahıs (-s) Kuralları:**  
  - Genel: `verb + -s` (*develop → develops, run → runs*)  
  - `-ch, -sh, -ss, -x, -o`: `verb + -es` (*watch → watches, fix → fixes, go → goes*)  
  - Sessiz \+ `y`: `y` düşer `verb + -ies` (*study → studies, try → tries*)

**Detaylı Anlatım:** Geniş zaman, eylemin konuşma anında yapıldığını değil; genel olarak, periyodik olarak veya alışkanlık gereği yapıldığını ifade eder.

En kritik kural: `He / She / It` özneleri olumlu cümlede fiile mutlaka `-s / -es / -ies` takısı alır. Ancak cümle olumsuz (`doesn't`) veya soru (`does`) olduğunda, ek yardımcı fiile geçtiği için **ana fiil çıplak (V1) haline döner**.

**Canlı Mini Diyalog (Real-Life Scenario):**

> **Lead:** Does your automated script backup the database every night?  
> **Engineer:** Yes, it does. It runs at midnight and uploads the archive to cloud storage.  
> **Lead:** What happens if the backup fails?  
> **Engineer:** It sends an urgent alert message to our Discord channel.

**Sık Yapılan Hatalar:**

* ❌ *Hatalı:* He work as a software engineer at a startup.  
  ✔️ *Doğru:* **He works as a software engineer at a startup.** *(Açıklama: He/She/It olumlu cümlede fiile \-s takısı alır).*  
* ❌ *Hatalı:* She doesn't writes backend code.  
  ✔️ *Doğru:* **She doesn't write backend code.** *(Açıklama: 'doesn't' varken fiildeki \-s düşer).*  
* ❌ *Hatalı:* I am live in Ankara.  
  ✔️ *Doğru:* **I live in Ankara.** *(Açıklama: Eylem fiili varken 'am/is/are' eklenmez).*

**Genişletilmiş Örnek Cümleler:**

1. 🇬🇧 *I write clean, modular, and testable code in Kotlin.* → 🇹🇷 Kotlin dilinde temiz, modüler ve test edilebilir kod yazarım.  
2. 🇬🇧 *He manages the cloud infrastructure on Google Cloud Platform.* → 🇹🇷 O, Google Cloud Platform üzerindeki bulut altyapısını yönetir.  
3. 🇬🇧 *The background service synchronizes local data with the remote server.* → 🇹🇷 Arka plan servisi, yerel verileri uzak sunucu ile senkronize eder.  
4. 🇬🇧 *We do not store plain-text passwords in the user table.* → 🇹🇷 Kullanıcı tablosunda düz metin şifreler saklamayız.  
5. 🇬🇧 *Does this open-source library support asynchronous operations?* → 🇹🇷 Bu açık kaynaklı kütüphane eşzamansız (asenkron) işlemleri destekliyor mu?  
6. 🇬🇧 *Water boils at 100 degrees Celsius.* → 🇹🇷 Su 100 santigrat derecede kaynar (Bilimsel gerçek).  
7. 🇬🇧 *They usually release software updates on the first Monday of each month.* → 🇹🇷 Genellikle her ayın ilk pazartesi günü yazılım güncellemeleri yayınlarlar.  
8. 🇬🇧 *Why does the application crash on older Android versions?* → 🇹🇷 Uygulama eski Android sürümlerinde neden çöküyor?  
9. 🇬🇧 *She analyzes user behavior metrics to improve application retention.* → 🇹🇷 Uygulamada kalma oranını artırmak için kullanıcı davranış metriklerini analiz eder.  
10. 🇬🇧 *Do you use Git for version control in your personal projects?* → 🇹🇷 Kişisel projelerinizde sürüm kontrolü için Git kullanıyor musunuz?

## [A1_G05] Adverbs of Frequency (Always, Usually, Often, Sometimes, Never)

**Kısaca ne işe yarar:** Bir eylemin hangi sıklıkla tekrarlandığını veya hangi olasılıkla yapıldığını ifade etmek için kullanılır.

**Görsel Şema / Zihin Haritası (Visual Mind-Map):**

```
                SIKLIK GÖSTERGESİ (Frequency Speedometer)

 0% ──────────────────────────────────────────────────────────── 100%
 │       │             │             │             │            │
NEVER  RARELY      SOMETIMES       OFTEN        USUALLY      ALWAYS
(Asla) (Nadiren)    (Bazen)      (Sık sık)    (Genellikle) (Her zaman)

                          CÜMLE İÇİ KONUM KURALI
                          ──────────────────────
1. Normal Fiilden ÖNCE  :  [Özne] + ALWAYS/OFTEN + [Fiil]  (I always test code.)
2. 'To Be'den SONRA     :  [Özne] + AM/IS/ARE + ALWAYS     (He is always busy.)
3. Modal ile Fiil ARASI :  [Özne] + CAN + ALWAYS + [Fiil]  (You can always ask.)
```

**Kural / Yapı Tablosu:**

| Sıklık Zarfı | Yüzdelik Değer | Türkçe Anlamı | Örnek Cümle |
|:---|:---|:---|:---|
| **Always** | %100 | Her zaman | *I always use version control.* |
| **Usually / Normally** | %80–90 | Genellikle | *We usually deploy in the morning.* |
| **Often / Frequently** | %60–70 | Sık sık | *She often writes technical articles.* |
| **Sometimes** | %50 | Bazen | *Sometimes bugs occur in production.* |
| **Rarely / Seldom** | %10–20 | Nadiren | *Servers are rarely down.* |
| **Never** | %0 | Asla / Hiçbir zaman | *I never share sensitive API keys.* |

**Detaylı Anlatım:** Sıklık zarfları "How often do you...?" (Ne sıklıkla ... yaparsın?) sorusuna yanıt verir.

*Kritik Kurallar:*

1. **Never ve Rarely:** Yapıca olumlu görünen cümleye tek başlarına olumsuzluk katarlar. Çift olumsuzluk kuralı gereği yanlarına `don't / doesn't` **kesinlikle gelmez**.  
2. **Yerleşim:** Asıl fiillerin soluna (önüne), ancak `am / is / are` fiillerinin sağına (arkasına) yerleşirler.  
3. *Sometimes* ve *Usually* cümlenin en başında da kullanılabilir (*"Sometimes I work on weekends"*).

**Canlı Mini Diyalog (Real-Life Scenario):**

> **Interviewer:** How often do you write documentation for your code?  
> **Candidate:** I **always** write README files and inline comments for public functions.  
> **Interviewer:** That is great. Are you **ever** late for team standup meetings?  
> **Candidate:** No, I am **never** late. I am **usually** online ten minutes before the meeting starts.

**Sık Yapılan Hatalar:**

* ❌ *Hatalı:* I don't never push untested code.  
  ✔️ *Doğru:* **I never push untested code.** *(Açıklama: 'Never' zaten olumsuzluk içerir, 'don't' kullanılmaz).*  
* ❌ *Hatalı:* He often is busy with client calls.  
  ✔️ *Doğru:* **He is often busy with client calls.** *(Açıklama: 'To be' fiilinden sonra gelmelidir).*  
* ❌ *Hatalı:* I check always my email in the morning.  
  ✔️ *Doğru:* **I always check my email in the morning.** *(Açıklama: Asıl fiilden önce gelmelidir).*

**Genişletilmiş Örnek Cümleler:**

1. 🇬🇧 *We always write comprehensive integration tests before a major release.* → 🇹🇷 Büyük bir sürümden önce her zaman kapsamlı entegrasyon testleri yazarız.  
2. 🇬🇧 *The staging server is usually updated every evening.* → 🇹🇷 Test sunucusu genellikle her akşam güncellenir.  
3. 🇬🇧 *I often participate in open-source developer discussions on GitHub.* → 🇹🇷 GitHub'daki açık kaynak geliştirici tartışmalarına sık sık katılırım.  
4. 🇬🇧 *Network latency is sometimes unpredictable during peak traffic hours.* → 🇹🇷 Yoğun trafik saatlerinde ağ gecikmesi bazen öngörülemez olabilir.  
5. 🇬🇧 *Our database administrator never disables security firewalls in production.* → 🇹🇷 Veritabanı yöneticimiz canlı ortamda güvenlik duvarlarını asla devre dışı bırakmaz.  
6. 🇬🇧 *She rarely misses our daily morning standup meeting.* → 🇹🇷 O, günlük sabah durum toplantımızı nadiren kaçırır.  
7. 🇬🇧 *Do you usually prefer dark theme or light theme in your IDE?* → 🇹🇷 IDE'nizde genellikle koyu temayı mı yoksa açık temayı mı tercih edersiniz?  
8. 🇬🇧 *He is always willing to help junior developers with their technical questions.* → 🇹🇷 Kıdemsiz geliştiricilere teknik sorularında her zaman yardım etmeye isteklidir.  
9. 🇬🇧 *We seldom experience data loss thanks to our automated daily backups.* → 🇹🇷 Otomatik günlük yedeklemelerimiz sayesinde nadiren veri kaybı yaşarız.  
10. 🇬🇧 *Software engineers always need to learn new technologies continuously.* → 🇹🇷 Yazılım mühendislerinin her zaman sürekli yeni teknolojiler öğrenmesi gerekir.

## [A1_G06] Present Continuous Tense (Şimdiki Zaman)

**Kısaca ne işe yarar:** Konuşma anında gerçekleşen anlık eylemleri, şu sıralar üzerinde çalışılan geçici durumları ve kesinleşmiş yakın gelecek planlarını ifade etmek için kullanılır.

**Görsel Şema / Zihin Haritası (Visual Mind-Map):**

```
                ZAMAN ÇİZELGESİ (Present Continuous Timeline)

                                   KONUŞMA ANI (Now)
Past ─────────────────────────────────────[ ⚡ ]──────────────────────────────────► Future

                       ACTION IN PROGRESS: "I am coding now."
                      (Eylem şu anda devam ediyor, bitmedi)

                       CÜMLE FORMÜLÜ (2 Zorunlu Ayak)
                       ─────────────────────────────
                  [ÖZNE]  +  [AM / IS / ARE]  +  [V-ING]
                     I             am             writing code.
                    She            is             debugging.
                   They            are            testing.
```

**Kural / Yapı Tablosu:**

| Cümle Türü | Formül | Örnek |
|:---|:---|:---|
| **Olumlu (+)** | `Özne + am/is/are + V-ing` | *I am building an Android app.* |
| **Olumsuz (-)** | `Özne + am not/isn't/aren't + V-ing` | *The server is not responding right now.* |
| **Soru (?)** | `Am/Is/Are + Özne + V-ing?` | *Are you testing the payment flow?* |
| **Zaman İfadeleri** | *now, right now, at the moment, currently, this week, these days, at present* | |

* **\-ing Yazım Kuralları:**  
  - Genel: `verb + -ing` (*work → working, test → testing*)  
  - Sessiz \+ `-e`: `-e` düşer (*write → writing, create → creating*)  
  - 1 heceli, sessiz-sesli-sessiz: Son harf çiftlenir (*run → running, stop → stopping*)

**Detaylı Anlatım:** Present Continuous Tense'in vazgeçilmez iki unsuru vardır: **To Be (am/is/are)** ve fiilin sonundaki **\-ing** takısı.

*Durum Fiilleri (Stative Verbs) Kuralı:* Duyu, duygu, zihinsel durum ve sahiplik bildiren fiiller (eylem içermeyenler) şimdiki zamanla (-ing) **kullanılmazlar**; geniş zamanla ifade edilirler: *know, want, need, understand, believe, like, love, remember, see, hear, belong, seem*.

- *"I am understanding you."* ❌ → *"I understand you."* ✔️  
- *"He is wanting a coffee."* ❌ → *"He wants a coffee."* ✔️

**Canlı Mini Diyalog (Real-Life Scenario):**

> **Team Lead:** Hi Oğuzhan, what are you working on right now?  
> **Oğuzhan:** I am currently implementing the biometric login feature with Jetpack Compose.  
> **Team Lead:** Are you experiencing any issues with the fingerprint API?  
> **Oğuzhan:** No, everything is working smoothly at the moment.

**Sık Yapılan Hatalar:**

* ❌ *Hatalı:* I debugging the authentication issue right now.  
  ✔️ *Doğru:* **I am debugging the authentication issue right now.** *(Açıklama: 'am/is/are' yardımcı fiili unutulamaz).*  
* ❌ *Hatalı:* I am knowing how to fix this bug.  
  ✔️ *Doğru:* **I know how to fix this bug.** *(Açıklama: 'know' bir durum fiilidir, \-ing almaz).*  
* ❌ *Hatalı:* Every morning I am checking server status.  
  ✔️ *Doğru:* **Every morning I check server status.** *(Açıklama: Rutinler için Present Simple kullanılır).*

**Genişletilmiş Örnek Cümleler:**

1. 🇬🇧 *The frontend team is redesigning the user profile screen today.* → 🇹🇷 Ön yüz ekibi bugün kullanıcı profil ekranını yeniden tasarlıyor.  
2. 🇬🇧 *Why is the background worker process consuming so much memory?* → 🇹🇷 Arka plan çalışan işlemi neden bu kadar çok bellek tüketiyor?  
3. 🇬🇧 *We are migrating our legacy monolith to a microservice architecture this month.* → 🇹🇷 Bu ay eski monolit yapımızı bir mikroservis mimarisine taşıyoruz.  
4. 🇬🇧 *The CI/CD pipeline is currently running automated tests on the server.* → 🇹🇷 CI/CD hattı şu anda sunucuda otomatik testleri çalıştırıyor.  
5. 🇬🇧 *Are you listening to the tech podcast or attending the virtual standup?* → 🇹🇷 Teknoloji podcast'ini mi dinliyorsun yoksa sanal durum toplantısına mı katılıyorsun?  
6. 🇬🇧 *He is not answering his phone because he is presenting the project demo.* → 🇹🇷 Telefonuna cevap vermiyor çünkü proje demosunu sunuyor.  
7. 🇬🇧 *Our database is handling thousands of concurrent requests right now.* → 🇹🇷 Veritabanımız şu anda binlerce eşzamanlı isteği işliyor.  
8. 🇬🇧 *I am learning how to build deep learning models with PyTorch this semester.* → 🇹🇷 Bu dönem PyTorch ile derin öğrenme modelleri oluşturmayı öğreniyorum.  
9. 🇬🇧 *The security team is investigating an unauthorized login attempt.* → 🇹🇷 Güvenlik ekibi yetkisiz bir giriş denemesini araştırıyor.  
10. 🇬🇧 *Look\! The download progress bar is increasing rapidly.* → 🇹🇷 Bak\! İndirme ilerleme çubuğu hızla artıyor.

## [A1_G07] Countable vs. Uncountable Nouns & Quantifiers (Some, Any, Much, Many, A lot of)

**Kısaca ne işe yarar:** İsimlerin tek tek sayılıp sayılamadığını ayırt etmek ve var olan miktarları (biraz, birkaç, hiç, çok, birçok) doğru belirteçlerle ifade etmek için kullanılır.

**Görsel Şema / Zihin Haritası (Visual Mind-Map):**

```
                ┌──────────────────────────────────────────────┐
                │        İSİM TÜRÜ VE MİKTAR BELİRTEÇ MATRİSİ  │
                └──────────────────────┬───────────────────────┘
                                       │
        ┌──────────────────────────────┴──────────────────────────────┐
        ▼                                                             ▼
[ SAYILABİLEN (Countable) ]                                  [ SAYILAMAYAN (Uncountable) ]
• a computer / three servers                                  • data, water, money, info, time
• Tekil ve çoğul (-s) olur                                    • Çoğul (-s) ALMAZ, 'a/an' ALMAZ
─────────────────────────────                                 ─────────────────────────────
• MANY  (Soru/Olumsuz: Many bugs)                             • MUCH  (Soru/Olumsuz: Much time)
• A FEW (Birkaç: A few files)                                 • A LITTLE (Biraz: A little help)
• SOME  (Olumlu: Some devices)                                • SOME  (Olumlu: Some memory)
• ANY   (Soru/Olumsuz: Any errors)                            • ANY   (Soru/Olumsuz: Any storage)
• A LOT OF (Olumlu: A lot of users)                           • A LOT OF (Olumlu: A lot of traffic)
```

**Kural / Yapı Tablosu:**

| Belirteç | Sayılabilen Çoğul İsimlerle | Sayılamayan İsimlerle | Cümle Türü Tercihi |
|:---|:---|:---|:---|
| **Some** | *some developers, some computers* | *some information, some coffee* | Genellikle **Olumlu (+)** & Teklif Soruları |
| **Any** | *any questions, any errors* | *any data, any money* | **Olumsuz (-)** & **Sorular (?)** |
| **Many** | *many servers, many files* | ❌ Kullanılmaz | Çoğunlukla **Olumsuz (-)** & **Sorular (?)** |
| **Much** | ❌ Kullanılmaz | *much time, much traffic* | Çoğunlukla **Olumsuz (-)** & **Sorular (?)** |
| **A lot of** | *a lot of users, a lot of devices* | *a lot of storage, a lot of memory* | Özellikle **Olumlu (+)** cümleler |

**Detaylı Anlatım:** *Sayılamayan İsimler (Uncountable Nouns):* Sıvılar, soyut kavramlar ve toplu materyaller tek tek sayılamaz. En kritik İngilizce sayılamayan isimler:

- *Information* (Bilgi)  
- *Advice* (Tavsiye)  
- *Software / Hardware* (Yazılım / Donanım)  
- *Money* (Para \- Dolar/TL sayılır ama "money" kelimesi sayılamaz)  
- *Knowledge* (Bilgi / Birikim)  
- *Equipment* (Ekipman)

*Some vs. Any Kuralı:*

- *Some* olumlu cümlelerde kullanılır: *"We have some updates."*  
- *Any* olumsuz ve sorularda kullanılır: *"We don't have any errors."* / *"Do you have any questions?"*  
- İstisna: Birine bir şey ikram veya rica ederken sorularda *some* kullanılır: *"Would you like some tea?"*

**Canlı Mini Diyalog (Real-Life Scenario):**

> **User:** I am having trouble with the installation. Do you have **any** advice?  
> **Support:** Sure\! We have **some** troubleshooting steps in our documentation. How **much** disk space do you have left?  
> **User:** I have **a lot of** free space, around 50 gigabytes, but I see **many** dependency warnings.  
> **Support:** Okay, let's fix those dependencies one by one.

**Sık Yapılan Hatalar:**

* ❌ *Hatalı:* The client gave us many useful informations.  
  ✔️ *Doğru:* **The client gave us a lot of useful information.** *(Açıklama: 'Information' sayılamaz; çoğul \-s ve many almaz).*  
* ❌ *Hatalı:* I don't have many time before the deployment deadline.  
  ✔️ *Doğru:* **I don't have much time before the deployment deadline.** *(Açıklama: 'Time' sayılamaz, much alır).*  
* ❌ *Hatalı:* We don't have some available servers.  
  ✔️ *Doğru:* **We don't have any available servers.** *(Açıklama: Olumsuz cümlede 'any' kullanılır).*

**Genişletilmiş Örnek Cümleler:**

1. 🇬🇧 *Do you have any previous experience with PostgreSQL or MySQL?* → 🇹🇷 PostgreSQL veya MySQL ile ilgili daha önceden hiç deneyiminiz var mı?  
2. 🇬🇧 *There is a lot of network traffic hitting our web application today.* → 🇹🇷 Bugün web uygulamamıza gelen çok fazla ağ trafiği var.  
3. 🇬🇧 *We do not have much RAM available on this staging virtual machine.* → 🇹🇷 Bu test sanal makinesinde fazla kullanılabilir RAM'imiz yok.  
4. 🇬🇧 *How many microservices are currently running inside the Kubernetes cluster?* → 🇹🇷 Kubernetes kümesi içinde şu anda kaç adet mikroservis çalışıyor?  
5. 🇬🇧 *The senior architect shared some valuable knowledge about system resilience.* → 🇹🇷 Kıdemli mimar, sistem dayanıklılığı hakkında bazı değerli bilgiler paylaştı.  
6. 🇬🇧 *Are there any open issues reported in the GitHub repository?* → 🇹🇷 GitHub deposunda bildirilmiş hiç açık sorun (issue) var mı?  
7. 🇬🇧 *We need to purchase some new hardware equipment for the server room.* → 🇹🇷 Sunucu odası için biraz yeni donanım ekipmanı satın almamız gerekiyor.  
8. 🇬🇧 *How much money does the cloud hosting cost per month?* → 🇹🇷 Bulut barındırma hizmetinin aylık maliyeti ne kadar paradır?  
9. 🇬🇧 *There are many developers contributing to this open-source project.* → 🇹🇷 Bu açık kaynaklı projeye katkıda bulunan birçok geliştirici var.  
10. 🇬🇧 *Would you like some coffee before we start the sprint planning meeting?* → 🇹🇷 Sprint planlama toplantısına başlamadan önce biraz kahve ister misiniz?

## [A1_G08] There is / There are & Prepositions of Place

**Kısaca ne işe yarar:** Bir nesnenin, durumun veya yerin var olduğunu belirtmek ve fiziksel konumunu (nerede bulunduğunu) tam olarak tarif etmek için kullanılır.

**Görsel Şema / Zihin Haritası (Visual Mind-Map):**

```
                ┌──────────────────────────────────────────────┐
                │          VARLIK VE MEKAN BİLDİRİMİ           │
                └──────────────────────┬───────────────────────┘
                                       │
                ┌──────────────────────┴──────────────────────┐
                ▼                                             ▼
     [ THERE IS (Tekil / Sayılamayan) ]             [ THERE ARE (Çoğul) ]
     • There is a bug on line 42.                   • There are 5 endpoints.
     • There is some water on desk.                 • There are many users.
     • (-) There isn't any issue.                   • (-) There aren't any bugs.
     • (?) Is there a problem?                      • (?) Are there any logs?

                         YER EDATLARI KUTU ŞEMASI (Prepositions)
                         ───────────────────────────────────────
             ┌───────┐            ┌───●───┐            ┌───────┐
             │  IN   │ (İçinde)   │  ON   │ (Üstünde)  │ UNDER │ (Altında)
             │   ●   │            │       │            │       │
             └───────┘            └───────┘            └───●───┘
             NEXT TO (Yanında)   BEHIND (Arkasında)   IN FRONT OF (Önünde)
             ● ┌─────┐           ┌─────┐              ┌─────┐
               │     │           │     │ ●          ● │     │
               └─────┘           └─────┘              └─────┘
```

**Kural / Yapı Tablosu:**

| Varlık Türü | Olumlu (+) | Olumsuz (-) | Soru (?) |
|:---|:---|:---|:---|
| **Tekil Sayılan** | `There is a + Noun` (*There is a file.*) | `There isn't a + Noun` | `Is there a + Noun?` |
| **Sayılamayan** | `There is some + Noun` (*There is data.*) | `There isn't any + Noun` | `Is there any + Noun?` |
| **Çoğul Sayılan** | `There are + Plural` (*There are files.*) | `There aren't any + Plural` | `Are there any + Plural?` |

* **Temel Yer Edatları:**  
  - `in`: içinde *(in the database, in the office, in Istanbul)*  
  - `on`: üzerinde / yüzeyinde *(on the screen, on the website, on line 10\)*  
  - `at`: noktasında / yanında *(at work, at home, at the station)*  
  - `under`: altında *(under the desk)*  
  - `behind`: arkasında *(behind the firewall)*  
  - `in front of`: önünde *(in front of the screen)*  
  - `next to / beside`: yanında *(next to the server)*  
  - `between`: arasında *(between two nodes)*

**Detaylı Anlatım:** *Have/Has vs. There is/are Ayrımı:*

- `Have / Has`: Özneye ait bir mülkiyeti ifade eder (*"The company has three servers"* \= Şirketin üç sunucusu var).  
- `There is / are`: Bir mekanda varlığı/bulunuşu ifade eder (*"There are three servers in the rack"* \= Kabinde üç sunucu var).

*In, On, At Kullanım Matrisi:*

- `In`: 3 boyutlu kapalı alanlar, odalar, şehirler, ülkeler (*in the room, in Turkey*).  
- `On`: Yüzey teması, web siteleri, ekranlar, sayfalar (*on the page, on the internet*).  
- `At`: Belirli bir buluşma noktası veya kurumsal konum (*at the office, at the door*).

**Canlı Mini Diyalog (Real-Life Scenario):**

> **QA Tester:** **Is there** any error message displayed **on** the mobile screen?  
> **Developer:** Yes, **there is** a warning dialog right **in front of** the login form.  
> **QA Tester:** **Are there** any logs **in** the console output?  
> **Developer:** Let me check... No, **there aren't** any crash logs behind this screen.

**Sık Yapılan Hatalar:**

* ❌ *Hatalı:* In the table has three errors.  
  ✔️ *Doğru:* **There are three errors in the table.** *(Açıklama: 'Var' demek için 'have/has' değil, 'there is/are' kullanılır).*  
* ❌ *Hatalı:* There is five developers in our team.  
  ✔️ *Doğru:* **There are five developers in our team.** *(Açıklama: Çoğul öznelerle 'there are' kullanılır).*  
* ❌ *Hatalı:* I saw this news in the website.  
  ✔️ *Doğru:* **I saw this news on the website.** *(Açıklama: Web siteleri ve ekranlar için 'on' kullanılır).*

**Genişletilmiş Örnek Cümleler:**

1. 🇬🇧 *There is an unexpected null pointer exception on line 84\.* → 🇹🇷 84\. satırda beklenmeyen bir null pointer istisnası var.  
2. 🇬🇧 *Are there any empty meeting rooms on the fourth floor of the building?* → 🇹🇷 Binanın dördüncü katında hiç boş toplantı odası var mı?  
3. 🇬🇧 *There are several microservices communicating behind the API gateway.* → 🇹🇷 API ağ geçidinin arkasında haberleşen birkaç mikroservis bulunmaktadır.  
4. 🇬🇧 *The backup hard drive is located under the main workstation desk.* → 🇹🇷 Yedekleme sabit diski ana iş istasyonu masasının altında yer almaktadır.  
5. 🇬🇧 *There is no documentation inside this legacy repository.* → 🇹🇷 Bu eski deponun içinde hiçbir dokümantasyon yoktur.  
6. 🇬🇧 *Please place the wireless router next to the fiber modem.* → 🇹🇷 Lütfen kablosuz yönlendiriciyi fiber modemin yanına yerleştirin.  
7. 🇬🇧 *There is some confidential data stored in this encrypted volume.* → 🇹🇷 Bu şifreli birimde saklanan bazı gizli veriler var.  
8. 🇬🇧 *The developer is sitting in front of a dual-monitor setup.* → 🇹🇷 Geliştirici, çift monitörlü bir kurulumun önünde oturuyor.  
9. 🇬🇧 *Is there any difference between these two database architectures?* → 🇹🇷 Bu iki veritabanı mimarisi arasında herhangi bir fark var mı?  
10. 🇬🇧 *The middleware sits between the web client and the database server.* → 🇹🇷 Ara katman yazılımı (middleware), web istemcisi ile veritabanı sunucusu arasında yer alır.

**Kural / Yapı Tablosu:**

| Cümle Türü | Formül | Örnek Cümle | Türkçe Anlamı |
|:---|:---|:---|:---|
| **Olumlu (+)** | `Özne + can + V1` | *She can design responsive UIs.* | Duyarlı arayüzler tasarlayabilir. |
| **Olumsuz (-)** | `Özne + cannot / can't + V1` | *I can't access the private repo.* | Özel depoya erişemiyorum. |
| **Soru (?)** | `Can + Özne + V1?` | *Can you review my pull request?* | Çekme isteğimi inceleyebilir misin? |
| **Kısa Cevap** | *Yes, I can. / No, he can't.* | *Yes, we can. / No, they can't.* | Evet, yapabilirim. / Hayır, yapamaz. |

**Detaylı Anlatım:** *Can* bir yardımcı fiildir (modal auxiliary verb). En büyük avantajı, tüm özneler için **tamamen aynı kalmasıdır**.

- *He / She / It* öznelerinde asla `-s` takısı almaz (*cans* diye bir kelime yoktur).  
- *Can* ile asıl fiil arasına asla **"to"** girmez (*can to code* ❌).  
- Olumsuz hali bitişik yazılan *cannot* veya günlük dilde kısaltılmış *can't* (/kɑːnt/ veya /kænt/) şeklindedir.

*Kullanım Alanları:*

1. **Yetenek:** *He can build Android apps with Jetpack Compose.*  
2. **İzin:** *You can test this endpoint without an authentication header.*  
3. **Rica:** *Can you share the database credentials securely?*  
4. **İmkan / Olasılık:** *Users can reset their passwords via email.*

**Canlı Mini Diyalog (Real-Life Scenario):**

> **Product Owner:** Can we deploy the new version by this Friday?  
> **Lead Developer:** Yes, we **can**, but we must finish the security testing first.  
> **Product Owner:** Can you check the payment gateway logs before the deploy?  
> **Lead Developer:** Sure, I **can** do that right away.

**Sık Yapılan Hatalar:**

* ❌ *Hatalı:* She can to speak three languages fluently.

* ❌ *Hatalı:* He cans write complex algorithms.  
  ✔️ *Doğru:* **He can write complex algorithms.** *(Açıklama: 'Can' hiçbir özneye göre ek almaz).*  
* ❌ *Hatalı:* I am can build web applications.  
  ✔️ *Doğru:* **I can build web applications.** *(Açıklama: 'Can' varken 'am/is/are' kullanılmaz).*

**Genişletilmiş Örnek Cümleler:**

9. 🇬🇧 *She can solve complex algorithmic problems very quickly.* → 🇹🇷 Karmaşık algoritmik problemleri çok hızlı bir şekilde çözebilir.

## [A1_G10] Past Simple: Verb To Be (Was / Were)

**Kısaca ne işe yarar:** Geçmişteki durumları, kişilerin geçmişteki kimliklerini, yaşlarını, duygularını ve geçmişte nerede bulunduklarını (eylem içermeyen geçmiş durumları) ifade etmek için kullanılır.

**Görsel Şema / Zihin Haritası (Visual Mind-Map):**

```
                PRESENT (Şimdiki Durum)         PAST (Geçmiş Durum)
                ───────────────────────         ───────────────────
                  AM / IS  (Tekil)      ───►            WAS
                  ARE      (Çoğul)      ───►           WERE

                                ÖZNE DAĞILIMI
                                ─────────────
                ┌─────────────────────┐       ┌─────────────────────┐
                │  I / HE / SHE / IT  │       │  YOU / WE / THEY    │
                └──────────┬──────────┘       └──────────┬──────────┘
                           ▼                                     ▼
                        [ WAS ]                               [ WERE ]
                "I was at home."                      "We were in the lab."
                "The server was down."                "They were ready."
```

**Kural / Yapı Tablosu:**

| Özne Grubu | Olumlu (+) | Olumsuz (-) | Soru (?) |
|:---|:---|:---|:---|
| **I / He / She / It** | `was` (*I was tired.*) | `was not` (`wasn't`) | `Was he at work?` |
| **You / We / They** | `were` (*They were late.*) | `were not` (`weren't`) | `Were you online?` |

* **Zaman Belirteçleri:** *yesterday, last night, last week, last month, last year, two days ago, in 2024*.

**Detaylı Anlatım:** *Was / Were*, Present Simple'daki *Am / Is / Are* yapısının geçmiş zaman formudur. Bu cümlelerde koşmak, yazmak, kodlamak gibi bir hareket fiili yer almaz. Sadece **durum, konum, nitelik, yaş veya meslek** bildirilir.

- *Yesterday:* Dün  
- *Last week / month:* Geçen hafta / ay  
- *Two hours ago:* İki saat önce  
- *In October 2025:* Ekim 2025'te

Soru yaparken *Was / Were* cümlenin en başına gelir (*"Were you in the office yesterday?"*).

**Canlı Mini Diyalog (Real-Life Scenario):**

> **DevOps:** Why **was** the website unavailable for twenty minutes yesterday?  
> **Backend:** There **was** a database connection spike after the marketing email.  
> **DevOps:** **Were** the backup servers active during the incident?  
> **Backend:** No, they **weren't** configured for automatic failover yet.

**Sık Yapılan Hatalar:**

* ❌ *Hatalı:* You was very helpful in the technical meeting.  
  ✔️ *Doğru:* **You were very helpful in the technical meeting.** *(Açıklama: 'You' öznesi daima 'were' alır).*  
* ❌ *Hatalı:* I was go to the technology conference yesterday.  
  ✔️ *Doğru:* **I went to the technology conference yesterday.** *(Açıklama: Eylem fiilleriyle was/were kullanılmaz; fiilin 2\. hali kullanılır).*  
* ❌ *Hatalı:* Did you at the office yesterday?  
  ✔️ *Doğru:* **Were you at the office yesterday?** *(Açıklama: Durum bildiren geçmiş zaman sorularında 'Did' değil, 'Was/Were' kullanılır).*

**Genişletilmiş Örnek Cümleler:**

1. 🇬🇧 *The server outage yesterday was caused by an unhandled null pointer error.* → 🇹🇷 Dünkü sunucu kesintisi, işlenmemiş bir null pointer hatasından kaynaklandı.  
2. 🇬🇧 *Were you in the office when the network connection dropped?* → 🇹🇷 Ağ bağlantısı koptuğunda ofiste miydiniz?  
3. 🇬🇧 *The legacy software architecture was not scalable for high traffic.* → 🇹🇷 Eski yazılım mimarisi yüksek trafik için ölçeklenebilir değildi.  
4. 🇬🇧 *We were very exhausted after working all night on the critical deployment.* → 🇹🇷 Kritik dağıtım üzerinde bütün gece çalıştıktan sonra çok yorgunduk.  
5. 🇬🇧 *She was the lead mobile developer on the SnapChef application.* → 🇹🇷 O, SnapChef uygulamasındaki baş mobil geliştiriciydi.  
6. 🇬🇧 *The client's initial budget was too low for a custom web platform.* → 🇹🇷 Müşterinin ilk bütçesi özel bir web platformu için çok düşüktü.  
7. 🇬🇧 *Why were the logs empty after the unexpected system crash?* → 🇹🇷 Beklenmeyen sistem çökmesinden sonra günlükler neden boştu?  
8. 🇬🇧 *I was not aware of the API specification changes until this morning.* → 🇹🇷 Bu sabaha kadar API spesifikasyon değişikliklerinin farkında değildim.  
9. 🇬🇧 *The workshop was very informative for all junior engineering students.* → 🇹🇷 Atölye çalışması tüm kıdemsiz mühendislik öğrencileri için çok bilgilendiriciydi.  
10. 🇬🇧 *They were our primary cloud hosting provider three years ago.* → 🇹🇷 Üç yıl önce onlar bizim birincil bulut barındırma sağlayıcımızdı.

## [A1_G11] Past Simple Tense (Regular & Irregular Verbs, Did)

**Kısaca ne işe yarar:** Geçmişte belirli bir zamanda başlamış ve tamamen bitmiş eylemleri, olaylar zincirini ve geçmiş deneyimleri anlatmak için kullanılan temel geçmiş zaman yapısıdır.

**Görsel Şema / Zihin Haritası (Visual Mind-Map):**

```
                ┌──────────────────────────────────────────────┐
                │          PAST SIMPLE ZAMAN MEKANİZMASI       │
                └──────────────────────┬───────────────────────┘
                                       │
        ┌──────────────────────────────┴──────────────────────────────┐
        ▼                                                             ▼
[ OLUMLU CÜMLELER (+) ]                                   [ OLUMSUZ (-) & SORU (?) ]
• Fiilin 2. Hali (V2) KULLANILIR                          • 'DID / DIDN'T' Devreye Girer
─────────────────────────────────                         ──────────────────────────
Düzenli: fix → fixed, code → coded                        (-) I didn't FIX the bug. (fixed değil!)
Düzensiz: write → WROTE, go → WENT                        (?) DID you write the code? (wrote değil!)
(SADECE olumlu cümlede V2 olur!)                          (Did varken fiil daima YALIN/V1 kalır!)
```

**Kural / Yapı Tablosu:**

| Cümle Türü | Formül | Örnek (Düzenli Fiil) | Örnek (Düzensiz Fiil) |
|:---|:---|:---|:---|
| **Olumlu (+)** | `Özne + V2` | *I fixed the bug.* | *I wrote the API.* (*write → wrote*) |
| **Olumsuz (-)** | `Özne + didn't + V1` | *I didn't fix the bug.* | *I didn't write the API.* |
| **Soru (?)** | `Did + Özne + V1?` | *Did you fix the bug?* | *Did you write the API?* |
| **Kısa Cevap** | *Yes, I did. / No, I didn't.* | *Yes, she did. / No, we didn't.* | |

* **En Sık Kullanılan Düzensiz Fiiller (Irregular Verbs \- V1 → V2):**  
  - *build → built, write → wrote, see → saw, go → went, come → came, take → took, make → made, find → found, give → gave, know → knew, buy → bought, send → sent, run → ran*.

**Detaylı Anlatım:** Past Simple Tense'in **1 Numaralı Altın Kuralı**: Fiilin 2\. hali (V2) **yalnızca ve sadece olumlu cümlelerde** kullanılır.

Cümleye olumsuzluk getiren `didn't` veya soru soran `did` yardımcı fiili girdiği anda, geçmiş zaman anlamı *did* tarafından üstlenilmiş olur. Bu yüzden ana eylem fiili mutlaka **en yalın (V1) haline geri döner**.

*Düzenli Fiil Kuralları:*

- `-e` ile bitenlere sadece `-d`: *create → created, optimize → optimized*.  
- Sessiz \+ `y` ile bitenlerde `y` düşer `-ied`: *study → studied, try → tried*.  
- Tek heceli sessiz-sesli-sessiz: Son harf çiftlenir: *stop → stopped, plan → planned*.

**Canlı Mini Diyalog (Real-Life Scenario):**

> **Lead Developer:** Did you test the payment gateway before pushing the commit?  
> **Junior Developer:** Yes, I **tested** it on staging and it **worked** without any errors.  
> **Lead Developer:** Great\! When did you deploy the changes?  
> **Junior Developer:** I **deployed** them about thirty minutes ago.

**Sık Yapılan Hatalar:**

* ❌ *Hatalı:* I didn't went to the office yesterday.  
  ✔️ *Doğru:* **I didn't go to the office yesterday.** *(Açıklama: 'didn't' varken fiil yalın V1 haline döner).*  
* ❌ *Hatalı:* Did you saw the error log?  
  ✔️ *Doğru:* **Did you see the error log?** *(Açıklama: 'did' olan soruda fiil 1\. halinde olur).*  
* ❌ *Hatalı:* We buyed a new dedicated server last month.  
  ✔️ *Doğru:* **We bought a new dedicated server last month.** *(Açıklama: 'Buy' düzensiz bir fiildir; 'buyed' olmaz, 'bought' olur).*

**Genişletilmiş Örnek Cümleler:**

1. 🇬🇧 *I resolved the merge conflict and deployed the hotfix yesterday afternoon.* → 🇹🇷 Dün öğleden sonra birleştirme (merge) çakışmasını giderdim ve acil yamayı dağıttım.  
2. 🇬🇧 *Did you receive my email regarding the updated database schema?* → 🇹🇷 Güncellenmiş veritabanı şemasına ilişkin e-postamı aldın mı?  
3. 🇬🇧 *We built the entire backend infrastructure using Node.js and MongoDB.* → 🇹🇷 Tüm arka uç altyapısını Node.js ve MongoDB kullanarak inşa ettik.  
4. 🇬🇧 *She didn't find any critical vulnerabilities during the automated security scan.* → 🇹🇷 Otomatik güvenlik taraması sırasında hiçbir kritik güvenlik açığı bulamadı.  
5. 🇬🇧 *The team decided to migrate the frontend codebase to React and Next.js.* → 🇹🇷 Ekip, ön yüz kod tabanını React ve Next.js'e taşımaya karar verdi.  
6. 🇬🇧 *What time did the automated backup script finish last night?* → 🇹🇷 Otomatik yedekleme betiği dün gece saat kaçta bitti?  
7. 🇬🇧 *He wrote a comprehensive script in Python to parse unstructured JSON data.* → 🇹🇷 Yapılandırılmamış JSON verilerini ayrıştırmak için Python'da kapsamlı bir betik yazdı.  
8. 🇬🇧 *They didn't understand the legacy architecture because there was no documentation.* → 🇹🇷 Dokümantasyon olmadığı için eski mimariyi anlamadılar.  
9. 🇬🇧 *I met with the client yesterday and discussed the new feature roadmap.* → 🇹🇷 Dün müşteriyle görüştüm ve yeni özellik yol haritasını tartıştım.  
10. 🇬🇧 *We tested the application on five different Android devices.* → 🇹🇷 Uygulamayı beş farklı Android cihazında test ettik.

## [A1_G12] Future Tense: Will vs. Be Going To

**Kısaca ne işe yarar:** Gelecekte gerçekleşecek eylemleri, önceden planlanmış niyetleri, konuşma anında aniden verilen kararları, sözleri ve geleceğe dair tahminleri ifade etmek için kullanılır.

**Görsel Şema / Zihin Haritası (Visual Mind-Map):**

```
                ┌──────────────────────────────────────────────┐
                │          GELECEK ZAMAN AYRIM RADARI          │
                └──────────────────────┬───────────────────────┘
                                       │
        ┌──────────────────────────────┴──────────────────────────────┐
        ▼                                                             ▼
[ WILL (Anlık / Spontane / Tahmin) ]                    [ BE GOING TO (Planlı / Kanıtlı) ]
• Konuşma anında karar verildi:                        • Önceden planlandı, organize edildi:
  ⚡ "The phone is ringing. I will answer it!"           📅 "I am going to travel to Germany next week."
• Kişisel tahmin (bence/belki):                        • Gözle görülür somut kanıt var:
  🔮 "I think AI will change coding."                    ☁️ "Look at those dark clouds! It is going to rain."
• Söz / Teklif:                                        • Formül:
  🤝 "I will help you with this bug."                    `am/is/are + going to + V1`
• Formül: `will + V1`
```

**Kural / Yapı Tablosu:**

| Yapı | Formül | Temel Kullanım Amacı | Örnek |
|:---|:---|:---|:---|
| **WILL (+)** | `Özne + will ('ll) + V1` | Anlık kararlar, sözler, teklifler, genel tahminler | *I will help you with that script.* |
| **WILL (-)** | `Özne + will not (won't) + V1` | Gelecekte yapılmayacak eylemler, ret bildirme | *I won't share this confidential key.* |
| **WILL (?)** | `Will + Özne + V1?` | İstek, rica ve geleceğe dair soru | *Will you attend the tech summit?* |
| **BE GOING TO (+)** | `Özne + am/is/are + going to + V1` | Önceden planlanmış niyetler, kanıtlı tahminler | *We are going to launch the beta next week.* |
| **BE GOING TO (-)** | `Özne + am not/isn't/aren't + going to + V1` | Planlanmamış / Gerçekleşmeyecek niyetler | *He isn't going to resign.* |
| **BE GOING TO (?)** | `Am/Is/Are + Özne + going to + V1?` | Plan ve niyet sorgulama | *Are you going to refactor this module?* |

**Detaylı Anlatım:** Türkçede hem *Will* hem de *Be going to* "-ecek / \-acak" olarak çevrilir; ancak arka plandaki zihinsel süreç farklıdır:

1. **Anlık Karar vs. Önceden Yapılan Plan:**  
   - Kapı çaldı: *"I will open it."* (O anda karar verildi → **Will**).  
   - Uçak biletini aldın, otelini tuttun: *"I am going to visit Berlin next month."* (Önceden planlandı → **Be going to**).  
2. **Kişisel Fikir vs. Somut Kanıt:**  
   - *"I think our app will win the hackathon."* (Kişisel inanç → **Will**).  
   - Sunucunun CPU kullanımı %99'a vurdu: *"Look at the metric\! The server is going to crash."* (Gözle görülür kanıt → **Be going to**).

**Canlı Mini Diyalog (Real-Life Scenario):**

> **Sarah:** The client wants a new report export feature by tomorrow morning\!  
> **Oğuzhan:** Don't panic. I **will write** the export script right now.  
> **Sarah:** Thank you\! What about the database migration?  
> **Oğuzhan:** We **are going to migrate** the database this Sunday at midnight; the maintenance window is already scheduled.

**Sık Yapılan Hatalar:**

* ❌ *Hatalı:* I am going to help you right now\!  
  ✔️ *Doğru:* **I will help you right now\!** *(Açıklama: Konuşma anında aniden verilen kararlarda 'will' kullanılır).*  
* ❌ *Hatalı:* I going to learn Kotlin next month.  
  ✔️ *Doğru:* **I am going to learn Kotlin next month.** *(Açıklama: 'Be going to' yapısındaki 'am/is/are' unutulamaz).*  
* ❌ *Hatalı:* She is going to buying a new laptop.  
  ✔️ *Doğru:* **She is going to buy a new laptop.** *(Açıklama: 'going to' sonrasındaki fiil yalın V1 kalır).*

**Genişletilmiş Örnek Cümleler:**

1. 🇬🇧 *I am going to deploy the new version of our mobile application tomorrow at 10 AM.* → 🇹🇷 Mobil uygulamamızın yeni sürümünü yarın saat 10:00'da yayına alacağım (Planlanmış).  
2. 🇬🇧 *Wait a second, I will check the server error logs immediately.* → 🇹🇷 Bir saniye bekle, sunucu hata günlüklerini derhal kontrol edeceğim (Anlık karar).  
3. 🇬🇧 *Look at the memory graph; the process is going to run out of RAM in a few minutes.* → 🇹🇷 Bellek grafiğine bak; işlem birkaç dakika içinde RAM yetersizliğine uğrayacak (Kanıta dayalı tahmin).  
4. 🇬🇧 *We are going to start developing the desktop version using PyQt6 next sprint.* → 🇹🇷 Gelecek sprint PyQt6 kullanarak masaüstü sürümünü geliştirmeye başlayacağız (Kararlaştırılmış niyet).  
5. 🇬🇧 *I promise I will not disclose any proprietary API keys.* → 🇹🇷 Tescilli hiçbir API anahtarını ifşa etmeyeceğime söz veriyorum (Söz).  
6. 🇬🇧 *Are you going to attend the upcoming European developer summit in Berlin?* → 🇹🇷 Berlin'deki yaklaşan Avrupa geliştirici zirvesine katılacak mısınız? (Plan sorgulama).  
7. 🇬🇧 *I think artificial intelligence will automate repetitive software testing tasks.* → 🇹🇷 Bence yapay zeka tekrarlayan yazılım testi görevlerini otomatikleştirecek (Kişisel öngörü).  
8. 🇬🇧 *The weather forecast says it is going to rain this afternoon.* → 🇹🇷 Hava durumu raporu bu öğleden sonra yağmur yağacağını söylüyor (Veriye dayalı tahmin).  
9. 🇬🇧 *Don't worry about the presentation slides, I will format them for you.* → 🇹🇷 Sunum slaytları için endişelenme, senin için onları biçimlendireceğim (Teklif).  
10. 🇬🇧 *They are not going to release the feature until all security tests pass.* → 🇹🇷 Tüm güvenlik testleri geçene kadar özelliği yayına almayacaklar (Planlanmış karar).
