## [B1_G01] Present Perfect Continuous (have/has been + V-ing)

**Kısaca ne işe yarar:** Geçmişte başlamış, şu ana kadar kesintisiz devam etmiş veya henüz bitmiş olup sonucu/etkisi şu anda bariz şekilde gözlemlenen süreçlerin **süresini ve devamlılığını** vurgulamak için kullanılır.

**Görsel Şema / Zihin Haritası (Visual Mind-Map):**

```
                ZAMAN SÜREÇ ÇİZELGESİ (Present Perfect Continuous)
                     3 SAAT ÖNCE BAŞLADI                   ŞU AN HÂLÂ SÜRÜYOR
Past ───────────────[ ══════════ DURATION / PROCESS ══════════ ]────────► Future
                     "I have been training the neural network for 3 hours."
                     (Eylemin süresi ve devamlılığı vurgulanıyor!)

                          CÜMLE FORMÜLÜ (3 Ayaklı Yapı)
                          ─────────────────────────────
               [ÖZNE]  +  [HAVE / HAS BEEN]  +  [V-ING]  +  [SINCE / FOR]
                 I            have been           coding        since 9 AM.
                She            has been         debugging       for two hours.
```

**Kural / Yapı Tablosu:**

| Cümle Türü | I / You / We / They | He / She / It |
|:---|:---|:---|
| **Olumlu (+)** | `have been + V-ing` (*I have been coding.*) | `has been + V-ing` (*He has been coding.*) |
| **Olumsuz (-)** | `haven't been + V-ing` (*We haven't been testing.*) | `hasn't been + V-ing` (*She hasn't been testing.*) |
| **Soru (?)** | `Have + Özne + been + V-ing?` | `Has + Özne + been + V-ing?` |
| **Zaman Belirteçleri** | *for 3 hours, since yesterday, all day, all week, lately, recently, how long* | |

**Detaylı Anlatım:** *Present Perfect Simple (have \+ V3) vs. Present Perfect Continuous (have been \+ V-ing):*

- **Simple Form (Sonuç Odaklı):** Eylemin tamamlanmış olup olmadığına ve *miktarına* odaklanır (*"I have written 5 API endpoints today"* \= Bugün 5 uç nokta yazdım, bitti).  
- **Continuous Form (Süreç Odaklı):** Eylemin *ne kadar süredir devam ettiğine* odaklanır (*"I have been writing API endpoints all morning"* \= Bütün sabahtır uç nokta yazmaktayım, eylem sürüyor).

*Geçici Etki Vurgusu:* Eylem az önce bitmiş olsa bile, fiziksel sonucu şu an görünüyorsa kullanılır:

- *"My eyes are tired because I have been staring at the terminal screen for six hours."* (Gözlerim yorgun çünkü 6 saattir ekrana bakmaktayım).

**Canlı Mini Diyalog (Real-Life Scenario):**

> **Senior Architect:** Why is the development server fan running so loud?  
> **ML Engineer:** I **have been training** a deep learning model for computer vision **since** 8 AM.  
> **Senior Architect:** How long **has it been processing** the image dataset?  
> **ML Engineer:** It **has been processing** the batches **for** about four hours without interruption.

**Sık Yapılan Hatalar:**

* ❌ *Hatalı:* I am working on this bug since three hours.  
  ✔️ *Doğru:* **I have been working on this bug for three hours.** *(Açıklama: Geçmişten bugüne süregelen süreçlerde Present Continuous değil, Present Perfect Continuous kullanılır; süre için 'for' gelir).*  
* ❌ *Hatalı:* I have been knowing Python for five years.  
  ✔️ *Doğru:* **I have known Python for five years.** *(Açıklama: 'Know' durum fiilidir, continuous (-ing) alamaz; Present Perfect Simple kullanılır).*  
* ❌ *Hatalı:* How long do you learn English?  
  ✔️ *Doğru:* **How long have you been learning English?** *(Açıklama: 'Ne kadar süredir...' sorusu bu zamanla sorulur).*

**Genişletilmiş Örnek Cümleler:**

1. 🇬🇧 *I have been debugging this memory leak issue since early this morning.* → 🇹🇷 Sabahın erken saatlerinden beri bu bellek sızıntısı sorununu ayıklamaktayım.  
2. 🇬🇧 *The automated backup service has been running smoothly without any failures for six months.* → 🇹🇷 Otomatik yedekleme servisi altı aydır hiçbir arıza olmadan sorunsuz bir şekilde çalışmaktadır.  
3. 🇬🇧 *How long have you been developing mobile applications with Jetpack Compose?* → 🇹🇷 Ne kadar süredir Jetpack Compose ile mobil uygulamalar geliştirmektesiniz?  
4. 🇬🇧 *She has been preparing the technical documentation for the upcoming European audit all week.* → 🇹🇷 Bütün haftadır yaklaşan Avrupa denetimi için teknik dokümantasyonu hazırlamaktadır.  
5. 🇬🇧 *We haven't been receiving any error alerts from the production server recently.* → 🇹🇷 Son zamanlarda canlı sunucudan herhangi bir hata uyarısı almamaktayız.  
6. 🇬🇧 *My hands are tired because I have been typing lines of code all afternoon.* → 🇹🇷 Ellerim yoruldu çünkü bütün öğleden sonradır kod satırları yazmaktayım.  
7. 🇬🇧 *The marketing team has been testing user conversion rates on the new landing page.* → 🇹🇷 Pazarlama ekibi yeni açılış sayfasında kullanıcı dönüşüm oranlarını test etmektedir.  
8. 🇬🇧 *Has the database team been monitoring query latency spikes during peak hours?* → 🇹🇷 Veritabanı ekibi yoğun saatlerdeki sorgu gecikmesi artışlarını izlemekte midir?  
9. 🇬🇧 *He has been learning full-stack web technologies since he enrolled in computer engineering.* → 🇹🇷 Bilgisayar mühendisliğine kaydolduğundan beri tam yığın web teknolojilerini öğrenmektedir.  
10. 🇬🇧 *They have been discussing the database partitioning strategy for more than two hours.* → 🇹🇷 İki saatten uzun bir süredir veritabanı bölümleme (partitioning) stratejisini tartışmaktalar.

## [B1_G02] Past Perfect Simple (had + V3)

**Kısaca ne işe yarar:** Geçmişte gerçekleşmiş iki olaydan **hangisinin daha önce (geçmişin de geçmişinde)** meydana geldiğini kronolojik olarak netleştirmek için kullanılır.

**Görsel Şema / Zihin Haritası (Visual Mind-Map):**

```
                ZAMAN ÇİZELGESİ (Past Perfect: Past of the Past)
     1. DAHA ESKİ OLAY (Had + V3)             2. DAHA YAKIN GEÇMİŞ (V2)        ŞU AN
Past ───────────[ 💥 EVENT 1 ]─────────────────────────[ 🛑 EVENT 2 ]─────────────► Present
        "The server HAD CRASHED               BEFORE I logged in."
        (Ben giriş yapmadan ÖNCE               sunucu zaten çökmüştü)

                          CÜMLE FORMÜLÜ (Tüm Özneler)
                          ───────────────────────────
                         [ÖZNE]  +  [HAD]  +  [V3]
                    I / He / They     had      already saved changes.
```

**Kural / Yapı Tablosu:**

| Cümle Türü | Formül (Tüm Özneler: I, You, He, She, We, They) | Örnek Cümle |
|:---|:---|:---|
| **Olumlu (+)** | `Özne + had ('d) + V3` | *The users had already reported the bug.* |
| **Olumsuz (-)** | `Özne + had not (hadn't) + V3` | *I hadn't saved my changes before the power cut.* |
| **Soru (?)** | `Had + Özne + V3?` | *Had you tested the API before deployment?* |
| **Bağlaçlar** | *before, after, by the time, when, as soon as, already, never* | |

**Detaylı Anlatım:** Geçmişte iki olay arka arkaya gerçekleştiğinde, sadece Past Simple (V2) kullanırsak olayların oluş sırası belirsizleşebilir. **Past Perfect (had \+ V3)**, geçmişteki "1 Numaralı (en eski) olayı" mühürler:

*Kalıp Cümle Yapıları:*

- `By the time + Past Simple (V2), Past Perfect (had + V3)`:  
  - *"By the time the CTO arrived, we had already fixed the outage."* (CTO geldiğinde biz kesintiyi çoktan düzeltmiştik).  
- `After + Past Perfect (had + V3), Past Simple (V2)`:  
  - *"After I had compiled the source code, I triggered the unit tests."* (Kaynak kodu derledikten sonra testleri tetikledim).

**Canlı Mini Diyalog (Real-Life Scenario):**

> **Security Officer:** How did the attacker gain access to the staging environment?  
> **DevOps:** **By the time** we deployed the firewall patch, the attacker **had already extracted** the session tokens.  
> **Security Officer:** **Had** anyone **audited** that endpoint **before** the incident occurred?  
> **DevOps:** No, we **had not reviewed** that legacy module yet.

**Sık Yapılan Hatalar:**

* ❌ *Hatalı:* By the time I arrived at the office, the meeting started.  
  ✔️ *Doğru:* **By the time I arrived at the office, the meeting had already started.** *(Açıklama: Toplantı varıştan daha önce başladığı için 'had started' olmalıdır).*  
* ❌ *Hatalı:* After I was saved the file, I closed the IDE.  
  ✔️ *Doğru:* **After I had saved the file, I closed the IDE.** *(Açıklama: 'After' yanına 'was saved' değil, Past Perfect 'had saved' alır).*  
* ❌ *Hatalı:* I didn't had configured the database before launching.  
  ✔️ *Doğru:* **I hadn't configured the database before launching.** *(Açıklama: Past Perfect olumsuzu 'hadn't \+ V3'tür).*

**Genişletilmiş Örnek Cümleler:**

1. 🇬🇧 *By the time we deployed the critical hotfix, hundreds of users had already reported the bug.* → 🇹🇷 Biz acil yamayı dağıtana kadar, yüzlerce kullanıcı hatayı çoktan bildirmişti.  
2. 🇬🇧 *I had saved all my source code changes before the sudden electrical power outage occurred.* → 🇹🇷 Ani elektrik kesintisi meydana gelmeden önce tüm kaynak kodu değişikliklerimi kaydetmiştim.  
3. 🇬🇧 *After the QA team had approved the pull request, we merged the feature into the main branch.* → 🇹🇷 Test ekibi çekme isteğini onayladıktan sonra, özelliği ana dala birleştirdik.  
4. 🇬🇧 *He hadn't encountered such a complex database deadlock until he worked on this enterprise project.* → 🇹🇷 Bu kurumsal projede çalışana kadar böylesine karmaşık bir veritabanı kilitlenmesiyle karşılaşmamıştı.  
5. 🇬🇧 *Had you verified the API authentication tokens before you triggered the automated integration tests?* → 🇹🇷 Otomatik entegrasyon testlerini tetiklemeden önce API kimlik doğrulama belirteçlerini doğrulamış mıydınız?  
6. 🇬🇧 *The server crashed because someone had deleted a critical configuration file by mistake.* → 🇹🇷 Birisi kritik bir yapılandırma dosyasını yanlışlıkla sildiği için sunucu çöktü.  
7. 🇬🇧 *She had already completed the database schema redesign when the client changed the requirements.* → 🇹🇷 Müşteri gereksinimleri değiştirdiğinde o veritabanı şemasının yeniden tasarımını çoktan tamamlamıştı.  
8. 🇬🇧 *By the end of 2025, our startup had expanded its merchant network across five major cities.* → 🇹🇷 2025'in sonuna gelindiğinde girişimimiz üye işyeri ağını beş büyük şehre genişletmişti.  
9. 🇬🇧 *They realized that the background service had stopped running three hours earlier.* → 🇹🇷 Arka plan servisinin üç saat önce çalışmayı durdurmuş olduğunu fark ettiler.  
10. 🇬🇧 *When the meeting began, the lead architect had not finalized the cloud migration budget yet.* → 🇹🇷 Toplantı başladığında, baş mimar bulut taşıma bütçesini henüz netleştirmemişti.

## [B1_G03] Second Conditional (Unreal Present / Hypotheses)

**Kısaca ne işe yarar:** Şimdiki zaman veya gelecek için **gerçek dışı, hayali, varsayımsal durumları** ve bunların gerçekleşmesi halinde ortaya çıkacak olası sonuçları ifade etmek için kullanılır.

**Görsel Şema / Zihin Haritası (Visual Mind-Map):**

```
                ┌──────────────────────────────────────────────┐
                │          SECOND CONDITIONAL (Hayal Odası)    │
                └──────────────────────┬───────────────────────┘
                                       │
        ┌──────────────────────────────┴──────────────────────────────┐
        ▼                                                             ▼
[ IF CÜMLESİ (Şu An Gerçek Dışı Şart) ]                [ ANA CÜMLE (Hayali Sonuç) ]
• Gramer olarak: Past Simple (V2)                      • Gramer olarak: WOULD / COULD + V1
• Anlam olarak: ŞİMDİKİ ZAMAN / GELECEK                • Anlam olarak: ŞİMDİKİ İHTİMAL
──────────────────────────────────────                 ───────────────────────────────
"If I HAD 100 GPU clusters,"                           "I WOULD TRAIN a massive LLM."
(Şu an 100 GPU'm yok - hayal ediyorum)                 (Devasa bir dil modeli eğitirdim)
```

**Kural / Yapı Tablosu:**

| Bölüm | Formül | Açıklama |
|:---|:---|:---|
| **Koşul (If Clause)** | `If + Past Simple (V2 / were)` | Şimdiki zamanda gerçek olmayan varsayım |
| **Sonuç (Main Clause)** | `would / could / might + V1` | Varsayım gerçekleşseydi ne olurdu |
| **Tavsiye Kalıbı** | `If I were you, I would + V1` | "Senin yerinde olsaydım..." (Önemli tavsiye) |

* **'Were' Kuralı:** Resmi dilde ve sınavlarda `I, He, She, It` özneleri için `was` yerine `were` kullanımı tercih edilir (*"If I were you..."*, *"If he were here..."*).

**Detaylı Anlatım:** First Conditional (Type 1\) ile Second Conditional (Type 2\) arasındaki en büyük fark **gerçeklik payıdır**:

- **Type 1 (Gerçekçi):** *"If I have free time tomorrow, I will help you."* (Yarın boş vaktim olabilir, gerçekçi).  
- **Type 2 (Hayali/Varsayımsal):** *"If I had free time today, I would help you."* (Ama bugün hiç vaktim yok, yoğunum; sadece hayal ediyorum).

*Gramer Geçmiş Zaman Ama Anlam Şimdiki Zaman:* Kural olarak `If + Past Simple` kullanılsa da, cümle kesinlikle geçmişi değil, **şu anki durumu** anlatır.

**Canlı Mini Diyalog (Real-Life Scenario):**

> **Junior:** If you **were** in my position, which backend technology **would you choose**?  
> **Senior Architect:** If I **were** building a high-concurrency real-time system, I **would choose** Go or Kotlin.  
> **Junior:** What **would happen** if we **used** Python instead?  
> **Senior Architect:** It **would work** fine, but we **would need** more horizontal server instances.

**Sık Yapılan Hatalar:**

* ❌ *Hatalı:* If I will have more memory, I would run the model locally.  
  ✔️ *Doğru:* **If I had more memory, I would run the model locally.** *(Açıklama: 'If' cümlesinde 'will' veya 'would' kullanılmaz; Past Simple kullanılır).*  
* ❌ *Hatalı:* If I was you, I would refactor that function.  
  ✔️ *Doğru:* **If I were you, I would refactor that function.** *(Açıklama: Tavsiye kalıbında 'If I were you' standarttır).*  
* ❌ *Hatalı:* If we used automated tests, we will save time.  
  ✔️ *Doğru:* **If we used automated tests, we would save time.** *(Açıklama: Type 2'de sonuç cümlesinde 'will' değil, 'would' kullanılır).*

**Genişletilmiş Örnek Cümleler:**

1. 🇬🇧 *If I had more high-performance computing resources, I would train a larger computer vision model.* → 🇹🇷 Daha fazla yüksek performanslı işlem kaynağım olsaydı, daha büyük bir bilgisayarlı görü modeli eğitirdim.  
2. 🇬🇧 *If I were you, I would separate the monolithic codebase into independent microservices.* → 🇹🇷 Senin yerinde olsaydım, monolitik kod tabanını bağımsız mikroservislere ayırırdım.  
3. 🇬🇧 *If we used an automated CI/CD pipeline, we wouldn't spend hours on manual deployments.* → 🇹🇷 Otomatik bir CI/CD işlem hattı kullansaydık, manuel dağıtımlara saatler harcamazdık.  
4. 🇬🇧 *What would you do if a zero-day security vulnerability were discovered in your production API?* → 🇹🇷 Canlı API'nizde bir sıfır gün güvenlik açığı keşfedilseydi ne yapardınız?  
5. 🇬🇧 *If the open-source library had better documentation, developers would adopt it much faster.* → 🇹🇷 Açık kaynaklı kütüphanenin daha iyi dokümantasyonu olsaydı, geliştiriciler onu çok daha hızlı benimserdi.  
6. 🇬🇧 *We could scale our infrastructure seamlessly if all our database services were containerized.* → 🇹🇷 Tüm veritabanı servislerimiz konteynerleştirilmiş olsaydı, altyapımızı sorunsuzca ölçeklendirebilirdik.  
7. 🇬🇧 *If she spoke English more fluently, she could easily work for international software companies.* → 🇹🇷 Daha akıcı İngilizce konuşabilseydi, uluslararası yazılım şirketlerinde kolayca çalışabilirdi.  
8. 🇬🇧 *If our startup won the seed investment round, we would hire three senior backend engineers immediately.* → 🇹🇷 Girişimimiz tohum yatırım turunu kazansaydı, derhal üç kıdemli arka uç mühendisi işe alırdık.  
9. 🇬🇧 *The application would run much faster if you cached the database queries in Redis.* → 🇹🇷 Veritabanı sorgularını Redis'te önbelleğe alsaydınız uygulama çok daha hızlı çalışırdı.  
10. 🇬🇧 *If there were no network latency constraints, distributed systems would be much simpler to design.* → 🇹🇷 Ağ gecikmesi kısıtlamaları olmasaydı, dağıtık sistemleri tasarlamak çok daha basit olurdu.

## [B1_G04] Defining & Non-Defining Relative Clauses (who, which, that, where, whose)

**Kısaca ne işe yarar:** İki ayrı kısa cümleyi birbirine bağlayarak bir insanı, nesneyi, mekanı veya aidiyeti niteleyen zengin ve akıcı sıfat cümlecikleri (relative clauses) oluşturmak için kullanılır.

**Görsel Şema / Zihin Haritası (Visual Mind-Map):**

```
                ┌──────────────────────────────────────────────┐
                │          İLGİ ZAMİRİ SEÇİM REHBERİ           │
                └──────────────────────┬───────────────────────┘
                                       │
        ┌──────────────────┬───────────┴───────────┬──────────────────┐
        ▼                  ▼                       ▼                  ▼
    [ İNSAN ]          [ NESNE / HAYVAN ]       [ MEKAN ]          [ SAHİPLİK ]
   WHO / THAT            WHICH / THAT             WHERE               WHOSE
• "The engineer       • "The framework        • "The office       • "The developer
   WHO fixed bug"        WHICH is fast"          WHERE we code"      WHOSE app won"

                   DEFINING vs. NON-DEFINING (Virgül Kuralı)
                   ────────────────────────────────────────
• DEFINING (Tanımlayıcı):     Virgül YOK! Bilgi cümlenin anlamı için ŞARTTIR.
                              "The engineer WHO built this system is our lead."
• NON-DEFINING (Ek Bilgi):   VİRGÜL VAR! Bilgi çıkarılsa da cümlenin ana fikri bozulmaz.
                              "FastAPI, WHICH is built on Starlette, is fast." (that KULLANILAMAZ!)
```

**Kural / Yapı Tablosu:**

| İlgi Zamiri | Nitelenen Varlık | Defining (Zorunlu Bilgi) | Non-Defining (Ekstra Bilgi) |
|:---|:---|:---|:---|
| **who** | İnsanlar | *The dev who wrote this...* | *Oğuzhan, who is our lead,...* |
| **which** | Nesneler, hayvanlar, kavramlar | *The bug which caused crash...* | *Docker, which is open-source,...* |
| **that** | İnsanlar veya nesneler | *The app that I use...* | ❌ **Non-defining'de KULLANILMAZ!** |
| **where** | Mekanlar, yerler | *The room where servers sit...* | *Istanbul, where our office is,...* |
| **whose** | Sahiplik (*-in, -ın*) | *The engineer whose code won...* | *Google, whose cloud platform...* |

**Detaylı Anlatım:**

1. **Defining Relative Clauses (Tanımlayıcı):** Hangi nesneden/kişiden bahsettiğimizi belirtir. Cümleden çıkarılırsa anlam eksik kalır. **Virgül kullanılmaz.** *Who* ve *which* yerine günlük dilde **that** kullanılabilir:  
   - *"The developer who designed this API is talented."* (Hangi geliştirici? Bu API'yi tasarlayan).  
2. **Non-Defining Relative Clauses (Ek Bilgi Veren):** Zaten bilinen özel bir isim hakkında ekstra detay verir. İki **virgül arasında** yazılır.  
   - **2 Katı Kural:**  
     1. Asla **that** kullanılamaz; sadece *who, which, where, whose* kullanılır.  
     2. Cümleden çıkarılsa bile ana cümlenin anlamı tam kalır:  
     - *"PostgreSQL, which is an open-source database, supports JSON queries."*

**Canlı Mini Diyalog (Real-Life Scenario):**

> **Visitor:** Who is the engineer **who** gave the keynote speech on DeepFake detection?  
> **Coordinator:** That is Oğuzhan, **whose** research paper was published in a top tech journal.  
> **Visitor:** Is this the laboratory **where** the project was developed?  
> **Coordinator:** Yes, and this is the workstation **that** we used for model training.

**Sık Yapılan Hatalar:**

* ❌ *Hatalı:* Docker, that is a container platform, is very popular.  
  ✔️ *Doğru:* **Docker, which is a container platform, is very popular.** *(Açıklama: Non-defining (virgüllü) cümlelerde 'that' kullanılamaz; 'which' kullanılır).*  
* ❌ *Hatalı:* The engineer which wrote this algorithm is our CTO.  
  ✔️ *Doğru:* **The engineer who (veya that) wrote this algorithm is our CTO.** *(Açıklama: İnsanlar için 'which' değil, 'who' kullanılır).*  
* ❌ *Hatalı:* The city which we host our servers is Frankfurt.  
  ✔️ *Doğru:* **The city where we host our servers is Frankfurt.** *(Açıklama: Mekanda eylem gerçekleştiği için 'where' kullanılır).*

**Genişletilmiş Örnek Cümleler:**

1. 🇬🇧 *The software engineer who designed this microservice architecture is now our lead architect.* → 🇹🇷 Bu mikroservis mimarisini tasarlayan yazılım mühendisi şu anda bizim baş mimarımızdır.  
2. 🇬🇧 *FastAPI, which is built on Starlette and Pydantic, provides automated OpenAPI documentation.* → 🇹🇷 Starlette ve Pydantic üzerine inşa edilmiş olan FastAPI, otomatik OpenAPI dokümantasyonu sağlar.  
3. 🇬🇧 *The server room where we keep our physical hardware racks is strictly climate-controlled.* → 🇹🇷 Fiziksel donanım kabinlerimizi tuttuğumuz sunucu odası sıkı bir şekilde iklimlendirilmektedir.  
4. 🇬🇧 *The developer whose pull request resolved the authentication bug received a team bonus.* → 🇹🇷 Çekme isteği kimlik doğrulama hatasını çözen geliştirici bir ekip primi aldı.  
5. 🇬🇧 *This is the exact machine learning dataset that we utilized to train our YOLOv8 vehicle detector.* → 🇹🇷 Bu, YOLOv8 araç dedektörümüzü eğitmek için kullandığımız makine öğrenmesi veri setinin tam kendisidir.  
6. 🇬🇧 *Kotlin, which was created by JetBrains, is the preferred language for modern Android development.* → 🇹🇷 JetBrains tarafından yaratılmış olan Kotlin, modern Android geliştirme için tercih edilen dildir.  
7. 🇬🇧 *Do you know the security specialist who discovered the zero-day vulnerability in our API?* → 🇹🇷 API'mizdeki sıfır gün güvenlik açığını keşfeden güvenlik uzmanını tanıyor musunuz?  
8. 🇬🇧 *The cloud provider where we host our European servers offers a 99.99% uptime guarantee.* → 🇹🇷 Avrupa sunucularımızı barındırdığımız bulut sağlayıcısı %99.99 çalışma süresi garantisi sunmaktadır.  
9. 🇬🇧 *We need a database solution that can handle millions of concurrent read operations smoothly.* → 🇹🇷 Milyonlarca eşzamanlı okuma işlemini sorunsuzca yönetebilecek bir veritabanı çözümüne ihtiyacımız var.  
10. 🇬🇧 *Ajans360, where I completed my summer internship, specializes in digital software solutions.* → 🇹🇷 Yaz stajımı tamamladığım Ajans360, dijital yazılım çözümleri konusunda uzmanlaşmıştır.

## [B1_G05] Passive Voice (Present Simple, Past Simple, Future, Modals)

**Kısaca ne işe yarar:** Eylemi yapan kişinin (öznenin) bilinmediği, önemsiz olduğu veya doğrudan **yapılan eylemin ve etkilenen nesnenin** ön plana çıkarılmak istendiği durumlarda (teknik raporlar, güvenlik bildirimleri, haberler) kullanılır.

**Görsel Şema / Zihin Haritası (Visual Mind-Map):**

```
                ┌──────────────────────────────────────────────┐
                │          ACTIVE vs. PASSIVE MEKANİZMASI      │
                └──────────────────────┬───────────────────────┘
                                       │
        ┌──────────────────────────────┴──────────────────────────────┐
        ▼                                                             ▼
[ ACTIVE (Etken - Yapan Odaklı) ]                            [ PASSIVE (Edilgen - Nesne/Eylem Odaklı) ]
"The developer FIXED the bug."                               "The bug WAS FIXED (by the developer)."
 └─ Özne ───┘  └─ Fiil ─┘ └─ Nesne ─┘                         └─ Yeni Özne ─┘ └─ To Be + V3 ─┘ └─ Yapan ─┘

                         GENEL PASSIVE FORMÜLÜ
                         ─────────────────────
                 [NESNE]  +  [TO BE (Uygun Zaman)]  +  [V3]
```

**Kural / Yapı Tablosu:**

| Zaman / Yapı | Active (Etken) | Passive Formülü | Passive Örnek Cümle |
|:---|:---|:---|:---|
| **Present Simple** | *They encrypt passwords.* | `am / is / are + V3` | *Passwords are encrypted.* |
| **Past Simple** | *They fixed the bug.* | `was / were + V3` | *The bug was fixed yesterday.* |
| **Future (Will)** | *They will deploy the app.* | `will be + V3` | *The app will be deployed soon.* |
| **Modals (Can/Must)** | *You must protect data.* | `modal + be + V3` | *Data must be protected.* |
| **Present Perfect** | *They have merged the PR.* | `have / has been + V3` | *The PR has been merged.* |

**Detaylı Anlatım:** Passive Voice yapısında cümledeki nesne başa geçer ve cümlenin yeni öznesi olur. Yapan kişiyi belirtmek gerekirse cümlenin sonuna **"by \+ yapan kişi"** (*by the engineering team*) eklenir; ancak teknik metinlerde çoğu zaman bu kısım atılır.

*Neden Kullanılır?*

1. **Teknik ve Bilimsel Raporlar:** *"User input is validated on the server."* (Kimin doğruladığı değil, doğrulandığı önemlidir).  
2. **Yapan Bilinmediğinde:** *"The database was hacked."* (Kimin yaptığı henüz bilinmiyor).  
3. **Gizlilik & Nezaket:** *"A mistake was made."* (Kişiyi suçlamadan durumu bildirmek için).

**Canlı Mini Diyalog (Real-Life Scenario):**

> **Auditor:** How **are user passwords stored** in your database?  
> **Security Lead:** All passwords **are hashed and salted** using bcrypt before they **are written** to disk.  
> **Auditor:** When **will the next vulnerability scan be conducted**?  
> **Security Lead:** It **will be executed** automatically tonight at midnight.

**Sık Yapılan Hatalar:**

* ❌ *Hatalı:* The software was deploy yesterday.  
  ✔️ *Doğru:* **The software was deployed yesterday.** *(Açıklama: Passive yapıda fiil mutlaka 3\. halde (V3) olmalıdır).*  
* ❌ *Hatalı:* Passwords encrypt before saving.  
  ✔️ *Doğru:* **Passwords are encrypted before saving.** *(Açıklama: 'To be' yardımcı fiili unutulamaz).*  
* ❌ *Hatalı:* The file can download by everyone.  
  ✔️ *Doğru:* **The file can be downloaded by everyone.** *(Açıklama: Modal passivelerde 'modal \+ be \+ V3' kalıbı kullanılır).*

**Genişletilmiş Örnek Cümleler:**

1. 🇬🇧 *All sensitive user credentials are encrypted before being stored in the PostgreSQL database.* → 🇹🇷 Tüm hassas kullanıcı kimlik bilgileri PostgreSQL veritabanında saklanmadan önce şifrelenir.  
2. 🇬🇧 *The critical security vulnerability was discovered and patched within two hours.* → 🇹🇷 Kritik güvenlik açığı iki saat içinde keşfedildi ve yamalandı.  
3. 🇬🇧 *The new version of the mobile application will be released on the Google Play Store tomorrow.* → 🇹🇷 Mobil uygulamanın yeni sürümü yarın Google Play Store'da yayınlanacaktır.  
4. 🇬🇧 *Automated unit tests must be executed before any code is merged into the main branch.* → 🇹🇷 Herhangi bir kod ana dala birleştirilmeden önce otomatik birim testleri çalıştırılmalıdır.  
5. 🇬🇧 *The legacy server was shut down after all databases were successfully migrated to the cloud.* → 🇹🇷 Tüm veritabanları buluta başarıyla taşındıktan sonra eski sunucu kapatıldı.  
6. 🇬🇧 *Millions of asynchronous HTTP requests are processed by our load balancer every minute.* → 🇹🇷 Yük dengeleyicimiz tarafından her dakika milyonlarca eşzamansız HTTP isteği işlenmektedir.  
7. 🇬🇧 *The pull request has already been reviewed and approved by two senior developers.* → 🇹🇷 Çekme isteği iki kıdemli geliştirici tarafından şimdiden incelendi ve onaylandı.  
8. 🇬🇧 *Can this PDF report be exported automatically at the end of each fiscal month?* → 🇹🇷 Bu PDF raporu her mali ayın sonunda otomatik olarak dışa aktarılabilir mi?  
9. 🇬🇧 *The database backup files were uploaded to a secure off-site cold storage vault.* → 🇹🇷 Veritabanı yedekleme dosyaları güvenli bir tesis dışı soğuk depolama kasasına yüklendi.  
10. 🇬🇧 *Special permissions are required in order to modify system environment variables.* → 🇹🇷 Sistem ortam değişkenlerini değiştirmek için özel izinler gereklidir.

## [B1_G06] Modals of Deduction & Speculation in the Present (Must be, Can't be, Might/Could be)

**Kısaca ne işe yarar:** Mevcut kanıtlara veya duruma bakarak şimdiki zaman hakkında **kesin çıkarımlarda bulunmak (%95 kesinlik)** ya da **ihtimaller ve olasılıklar yürütmek (%50 ihtimal)** için kullanılır.

**Görsel Şema / Zihin Haritası (Visual Mind-Map):**

```
                KESİNLİK VE ÇIKARIM GÖSTERGESİ (Deduction Gauge)
 0% ────────────────────────────────── 50% ────────────────────────────────── 100%
 │                                      │                                      │
CAN'T BE                           MIGHT / COULD                            MUST BE
(İmkansız / Kesinlikle değil)      (Belki / Olası)                          (Kesinlikle öyle / Olmalı)
"The port CAN'T BE open,           "The network MIGHT BE slow               "The CPU is at 100%,
 we closed it." (%95 olumsuz)       due to maintenance." (%50)               a process MUST BE looping." (%95)
```

**Kural / Yapı Tablosu:**

| Modal Yapısı | Kesinlik Derecesi | Mantıksal Anlamı | Örnek Cümle |
|:---|:---|:---|:---|
| **Must be / V1** | ~%95 Olumlu Kesinlik | Kanıtlar çok güçlü; *kesinlikle öyle olmalı* | *The light is red; the server must be down.* |
| **Can't be / V1** | ~%95 Olumsuz Kesinlik | İmkansız; *kesinlikle öyle olamaz* | *This can't be a network bug, ping is 1ms.* |
| **Might / May be** | ~%40–50 İhtimal | Belki öyle olabilir; *ihtimal dahilinde* | *It might be a caching issue.* |
| **Could be / V1** | ~%40–50 İhtimal | Mümkün; *olabilir* | *The database could be locked.* |

* **Formül:** `Özne + must / can't / might / could + V1 (veya be + Sıfat/İsim)`

**Detaylı Anlatım:** Buradaki *Must* ve *Can't*, zorunluluk veya yetenek bildirmez; **mantıksal bir çıkarım (deduction)** bildirir.

1. **Must be (Güçlü Pozitif Çıkarım):** Elinizde çok net bir kanıt vardır.  
   - *"Port 8080 is not responding, another process must be using it."* (Port yanıt vermiyor, başka bir işlem kullanıyor olmalı).  
2. **Can't be (Güçlü Negatif Çıkarım):** Bir durumun mantıksal olarak imkansız olduğunu gösterir (*Must not* çıkarım için kullanılmaz; yerine *Can't* kullanılır).  
   - *"He can't be in the office; his laptop is at home."* (Ofiste olamaz; bilgisayarı evde).  
3. **Might / Could be (Olasılık):** Emin değilsiniz, birkaç olasılıktan biridir.  
   - *"The slow response might be caused by database connection pooling."*

**Canlı Mini Diyalog (Real-Life Scenario):**

> **Developer:** The client says they cannot log in, but our auth server is fully operational.  
> **Lead:** Then they **must be entering** an incorrect password or an unverified email.  
> **Developer:** Could it be an expired JWT token issue?  
> **Lead:** It **can't be** a token issue because they haven't passed the login stage yet. It **might be** a browser cookie conflict.

**Sık Yapılan Hatalar:**

* ❌ *Hatalı:* The server doesn't respond; it mustn't be working.  
  ✔️ *Doğru:* **The server doesn't respond; it can't be working.** *(Açıklama: Mantıksal imkansızlık çıkarımında 'mustn't' değil, 'can't' kullanılır).*  
* ❌ *Hatalı:* He must is very tired after working all night.  
  ✔️ *Doğru:* **He must be very tired after working all night.** *(Açıklama: Modal sonrasında fiil yalın olmalıdır; 'is' değil, 'be' gelir).*  
* ❌ *Hatalı:* This error must to be a database deadlock.  
  ✔️ *Doğru:* **This error must be a database deadlock.** *(Açıklama: Modal sonrasında 'to' kullanılmaz).*

**Genişletilmiş Örnek Cümleler:**

1. 🇬🇧 *The server CPU usage is at 100%; an unoptimized infinite loop must be running in the background.* → 🇹🇷 Sunucu işlemci kullanımı %100'de; arka planda optimize edilmemiş sonsuz bir döngü çalışıyor olmalı.  
2. 🇬🇧 *This cannot be a database connection issue because all health check endpoints are returning 200 OK.* → 🇹🇷 Bu bir veritabanı bağlantısı sorunu olamaz çünkü tüm sağlık kontrolü uç noktaları 200 OK döndürüyor.  
3. 🇬🇧 *The sudden drop in application performance might be caused by an unindexed SQL query.* → 🇹🇷 Uygulama performansındaki ani düşüş, indekslenmemiş bir SQL sorgusundan kaynaklanıyor olabilir.  
4. 🇬🇧 *She is not answering her phone; she must be presenting the quarterly roadmap to the investors.* → 🇹🇷 Telefonuna cevap vermiyor; yatırımcılara üç aylık yol haritasını sunuyor olmalı.  
5. 🇬🇧 *The client can't be using an outdated version of our mobile app because forced updates are enabled.* → 🇹🇷 Müşteri mobil uygulamamızın eski bir sürümünü kullanıyor olamaz çünkü zorunlu güncellemeler etkindir.  
6. 🇬🇧 *There could be a network routing delay between the European client and our American database.* → 🇹🇷 Avrupalı istemci ile Amerikan veritabanımız arasında bir ağ yönlendirme gecikmesi olabilir.  
7. 🇬🇧 *The system architecture looks extremely clean; a very experienced senior engineer must have designed it.* → 🇹🇷 Sistem mimarisi son derece temiz görünüyor; çok deneyimli kıdemli bir mühendis tasarlamış olmalı.  
8. 🇬🇧 *You have been coding for ten hours straight; you must be exhausted.* → 🇹🇷 Aralıksız on saattir kod yazıyorsun; bitkin düşmüş olmalısın.  
9. 🇬🇧 *The missing configuration key might be located in the local environment file.* → 🇹🇷 Eksik yapılandırma anahtarı yerel ortam (.env) dosyasında bulunuyor olabilir.  
10. 🇬🇧 *This library can't be compatible with modern Python versions because it hasn't been updated since 2018\.* → 🇹🇷 Bu kütüphane modern Python sürümleriyle uyumlu olamaz çünkü 2018'den beri güncellenmedi.

## [B1_G07] Used to & Would for Past Habits & States

**Kısaca ne işe yarar:** Geçmişte düzenli olarak yapılan ancak **artık tamamen terk edilmiş alışkanlıkları** ve geçmişte doğru olup günümüzde geçerliliğini yitirmiş durumları anlatmak için kullanılır.

**Görsel Şema / Zihin Haritası (Visual Mind-Map):**

```
                ┌──────────────────────────────────────────────┐
                │          USED TO vs. WOULD FARKI             │
                └──────────────────────┬───────────────────────┘
                                       │
        ┌──────────────────────────────┴──────────────────────────────┐
        ▼                                                             ▼
[ USED TO (Hem Durum Hem Eylem) ]                            [ WOULD (Sadece Tekrarlanan Eylem) ]
• Geçmiş Alışkanlık: "I used to code in C++."                 • Geçmiş Alışkanlık: "We would review code every Friday."
• Geçmiş Durum:       "I used to LIVE in Bolu."                • Geçmiş Durum:       ❌ KULLANILAMAZ!
                      "There used to BE a server."                                   ("I would live in Bolu" ❌)
─────────────────────────────────────────────                 ──────────────────────────────────────────
(Artık yapmıyorum / Artık orada yaşamıyorum)                  (Eski anıları nostaljik anlatırken eylemler için)
```

**Kural / Yapı Tablosu:**

| Yapı | Cümle Türü | Formül | Örnek Cümle |
|:---|:---|:---|:---|
| **Used to** | Olumlu (+) | `Özne + used to + V1` | *We used to maintain a monolithic architecture.* |
| **Used to** | Olumsuz (-) | `Özne + didn't use to + V1` | *I didn't use to write automated tests.* |
| **Used to** | Soru (?) | `Did + Özne + use to + V1?` | *Did you use to work with Java?* |
| **Would** | Olumlu (+) | `Özne + would ('d) + V1` | *Every morning, we would review our Git logs.* |

**Detaylı Anlatım:**

1. **Used to (Geçmiş Alışkanlıklar ve Durumlar):** Hem fiziksel hareket bildiren eylemler (*run, write, deploy*) hem de durum bildiren fiiller (*be, live, have, know, believe*) ile kullanılır.  
   - *"I used to have a slow computer (now I have a fast one)."* (Eski durum).  
   - *"I used to play League of Legends every weekend."* (Eski alışkanlık).  
2. **Would (Yalnızca Tekrarlanan Eylemler):** Geçmişteki tekrarlanan eylemleri nostaljik ve hikaye anlatımı tarzında ifade eder. **Durum fiilleriyle (stative verbs: live, be, know, have) kesinlikle KULLANILMAZ.**  
   - *"When we were in university, we would stay up all night to build prototypes."* ✔️  
   - *"I would live in Ankara."* ❌ (Durum fiilidir, used to olmalıdır: *"I used to live in Ankara"* ✔️).

*Önemli Olumsuzluk Kuralı:* Olumsuzda `didn't` geldiğinde sondaki `-d` harfi düşer: **didn't use to**.

**Canlı Mini Diyalog (Real-Life Scenario):**

> **Junior:** How did developers deploy software before Docker and Kubernetes?  
> **Senior Architect:** We **used to configure** physical servers manually, which **used to take** several days.  
> **Junior:** Did you use to write automation scripts?  
> **Senior Architect:** Yes, every Friday afternoon, we **would write** custom Bash scripts to backup our files.

**Sık Yapılan Hatalar:**

* ❌ *Hatalı:* I would have a desktop computer when I was in high school.  
  ✔️ *Doğru:* **I used to have a desktop computer when I was in high school.** *(Açıklama: 'Have' durum fiilidir; geçmiş durumlar için 'would' değil, 'used to' kullanılır).*  
* ❌ *Hatalı:* I didn't used to like TypeScript, but now I love it.  
  ✔️ *Doğru:* **I didn't use to like TypeScript, but now I love it.** *(Açıklama: 'didn't' varken 'used' değil, 'use' yazılır).*  
* ❌ *Hatalı:* I am used to code in Python. (Eski alışkanlık kastedilirken)  
  ✔️ *Doğru:* **I used to code in Python.** *(Açıklama: 'am used to' alışkın olmak demektir; geçmiş alışkanlık 'used to \+ V1'dir).*

**Genişletilmiş Örnek Cümleler:**

1. 🇬🇧 *We used to maintain a complex monolithic architecture before migrating our services to Docker containers.* → 🇹🇷 Servislerimizi Docker konteynerlerine taşımadan önce karmaşık bir monolitik mimari sürdürürdük.  
2. 🇬🇧 *Every Friday morning, our engineering team would gather in the lounge to review open pull requests.* → 🇹🇷 Her cuma sabahı mühendislik ekibimiz açık çekme isteklerini incelemek için salonda toplanırdı.  
3. 🇬🇧 *I didn't use to write unit tests for my freelance projects, but now I practice test-driven development.* → 🇹🇷 Serbest zamanlı projelerim için birim testleri yazmazdım ama şimdi test güdümlü geliştirme uyguluyorum.  
4. 🇬🇧 *There used to be a physical data center in the basement of our company headquarters.* → 🇹🇷 Şirket genel merkezimizin bodrum katında fiziksel bir veri merkezi bulunurdu.  
5. 🇬🇧 *Did you use to develop native Android applications with Java before Kotlin became standard?* → 🇹🇷 Kotlin standart hale gelmeden önce Java ile yerel Android uygulamaları geliştirir miydiniz?  
6. 🇬🇧 *During our university hackathons, we would drink coffee all night and deploy prototypes by sunrise.* → 🇹🇷 Üniversite hackathonlarımız sırasında bütün gece kahve içer ve gün doğumuna kadar prototipleri yayına alırdık.  
7. 🇬🇧 *She used to live in Bolu while she was completing her computer engineering bachelor's degree.* → 🇹🇷 Bilgisayar mühendisliği lisans derecesini tamamlarken Bolu'da yaşardı (artık yaşamıyor).  
8. 🇬🇧 *Our previous database solution used to crash whenever concurrent traffic exceeded ten thousand requests.* → 🇹🇷 Önceki veritabanı çözümümüz, eşzamanlı trafik on bin isteği aştığında çökerdi.  
9. 🇬🇧 *I used to play League of Legends competitively, but now I focus entirely on software development.* → 🇹🇷 Eskiden rekabetçi olarak League of Legends oynardım, ancak şimdi tamamen yazılım geliştirmeye odaklanıyorum.  
10. 🇬🇧 *When we were prototyping the embedded defense project, my cousin and I would test the stepper motors every weekend.* → 🇹🇷 Gömülü savunma projesini prototiplerken, kuzenim ve ben her hafta sonu adım motorlarını test ederdik.

## [B1_G08] Reported Speech (Statements & Questions with Tense Backshift)

**Kısaca ne işe yarar:** Bir başkasının söylediği sözleri, verdiği talimatları veya sorduğu soruları tırnak işareti kullanmadan dolaylı bir şekilde (zaman kaydırması kuralıyla) aktarmak için kullanılır.

**Görsel Şema / Zihin Haritası (Visual Mind-Map):**

```
                ┌──────────────────────────────────────────────┐
                │          TENSE BACKSHIFT (Zaman Kaydırma)    │
                └──────────────────────┬───────────────────────┘
                                       │
        ┌──────────────────────────────┴──────────────────────────────┐
        ▼                                                             ▼
[ DOĞRUDAN SÖZ (Direct Speech) ]                             [ DOLAYLI AKTARIM (Reported Speech) ]
• Present Simple (am/is/are, write)  ──────► Past Simple (was/were, wrote)
• Present Continuous (is writing)    ──────► Past Continuous (was writing)
• Present Perfect (have written)     ──────► Past Perfect (had written)
• Past Simple (wrote)                ──────► Past Perfect (had written)
• Will (will write)                  ──────► Would (would write)
• Can (can write)                    ──────► Could (could write)

                          SORU AKTARIMI (Düz Cümleye Dönüşür!)
                          ────────────────────────────────────
Direct:   "Where IS the server?"
Reported: He asked me where the server WAS. (Soru kalıbı kalkar, düz cümle dizilimi olur!)
```

**Kural / Yapı Tablosu:**

| Aktarım Türü | Doğrudan İfade (Direct) | Dolaylı İfade (Reported Speech) | Kural & Yapı |
|:---|:---|:---|:---|
| **Düz Cümle** | *"I am ready."* | *He said (that) he was ready.* | `said (that) + backshift` |
| **Kişiye Söylenen** | *"I will help you."* | *She told me that she would help me.* | `told + kişi (me/him) + that` |
| **Wh- Sorusu** | *"Where is the API key?"* | *He asked where the API key was.* | `asked + Wh- + Özne + Fiil` |
| **Yes/No Sorusu** | *"Do you know Kotlin?"* | *She asked if / whether I knew Kotlin.* | `asked + if/whether + Özne + Fiil` |

* **Zaman ve Yer Zarfları Değişimi:**  
  - *now → then*, *today → that day*, *yesterday → the day before*, *tomorrow → the next day*, *here → there*, *this → that*.

**Detaylı Anlatım:** Bir sözü aktarırken ana aktarım fiili geçmiş zamanda (*said, told, asked*) ise, cümlenin zamanı **bir adım geçmişe kayar (Tense Backshift)**.

*Say vs. Tell Ayrımı:*

- `Say`: Yanına doğrudan kişi zamiri almaz (*"He said that..."*).  
- `Tell`: Yanına mutlaka kime söylendiğini belirten nesne zamiri alır (*"He told me that..."* / *"He told Sarah that..."*).

*Soru Cümlelerinin Aktarımı:* Dolaylı aktarılan sorular artık gerçek bir soru değildir; bir bildirim cümlesidir. Bu yüzden **soru dizilimi (yardımcı fiil \+ özne) bozulur, normal düz cümle dizilimine (özne \+ fiil) döner**:

- *"Where do you store the logs?"* → *He asked me where I stored the logs.* (*where did I store* ❌).

**Canlı Mini Diyalog (Real-Life Scenario):**

> **Project Lead:** What did the client say during the morning review?  
> **Developer:** She **said that** the user interface **looked** very modern, but she **asked if** we **could optimize** the checkout page.  
> **Project Lead:** Did she mention the deadline?  
> **Developer:** Yes, she **told me that** they **would launch** the marketing campaign the following week.

**Sık Yapılan Hatalar:**

* ❌ *Hatalı:* He told that the server was down.  
  ✔️ *Doğru:* **He said that the server was down.** veya **He told me that the server was down.** *(Açıklama: 'Tell' yanına kime söylendiğini (me, us) almak zorundadır).*  
* ❌ *Hatalı:* She asked me where was the database.  
  ✔️ *Doğru:* **She asked me where the database was.** *(Açıklama: Aktarılan sorularda düz cümle dizilimi (Özne \+ Fiil) kullanılır).*  
* ❌ *Hatalı:* He said: "I am ready." \-\> He said that I was ready.  
  ✔️ *Doğru:* **He said that he was ready.** *(Açıklama: Zamirler aktaran kişiye göre uyarlanmalıdır).*

**Genişletilmiş Örnek Cümleler:**

1. 🇬🇧 *The client said that the payment gateway endpoint was returning a 500 internal server error.* → 🇹🇷 Müşteri, ödeme ağ geçidi uç noktasının 500 dahili sunucu hatası döndürdüğünü söyledi.  
2. 🇬🇧 *She told me that she would deploy the updated mobile application the following morning.* → 🇹🇷 Bana, ertesi sabah güncellenmiş mobil uygulamayı yayına alacağını söyledi.  
3. 🇬🇧 *The lead architect asked me whether the PostgreSQL database connection was properly encrypted.* → 🇹🇷 Baş mimar bana PostgreSQL veritabanı bağlantısının düzgün şekilde şifrelenip şifrelenmediğini sordu.  
4. 🇬🇧 *He asked where we stored the automated backup archives.* → 🇹🇷 Otomatik yedekleme arşivlerini nerede sakladığımızı sordu.  
5. 🇬🇧 *The security team reported that an unauthorized IP address had attempted to access the admin portal.* → 🇹🇷 Güvenlik ekibi, yetkisiz bir IP adresinin yönetici portalına erişmeye çalıştığını bildirdi.  
6. 🇬🇧 *She said that she had already refactored the entire user profile module.* → 🇹🇷 Tüm kullanıcı profili modülünü şimdiden yeniden düzenlemiş olduğunu söyledi.  
7. 🇬🇧 *The developer asked if I could review his pull request before the end of the sprint.* → 🇹🇷 Geliştirici, sprint bitmeden önce çekme isteğini inceleyip inceleyemeyeceğimi sordu.  
8. 🇬🇧 *They told us that they were migrating their servers to Google Cloud Platform.* → 🇹🇷 Bize, sunucularını Google Cloud Platform'a taşımakta olduklarını söylediler.  
9. 🇬🇧 *He explained that the sudden latency spike was caused by unindexed database queries.* → 🇹🇷 Ani gecikme artışının indekslenmemiş veritabanı sorgularından kaynaklandığını açıkladı.  
10. 🇬🇧 *The product manager asked what time the maintenance window would finish that evening.* → 🇹🇷 Ürün yöneticisi, o akşam bakım aralığının saat kaçta biteceğini sordu.

## [B1_G09] Complex Gerunds & Infinitives (Verbs changing meaning: remember, stop, forget, regret, try)

**Kısaca ne işe yarar:** Arkasından `-ing` (Gerund) veya `to + V1` (Infinitive) aldığında **anlamı bütünüyle değişen özel fiilleri** doğru bağlamda kullanmak için gereklidir.

**Görsel Şema / Zihin Haritası (Visual Mind-Map):**

```
                ┌──────────────────────────────────────────────┐
                │          ANLAM DEĞİŞTİREN FİİL MERKEZİ       │
                └──────────────────────┬───────────────────────┘
                                       │
        ┌──────────────────────────────┴──────────────────────────────┐
        ▼                                                             ▼
[ GERUND (-ing): Geçmiş Anı / Eylemin Kendisi ]             [ INFINITIVE (to V1): Görev / Hedef ]
• REMEMBER DOING: Geçmişte yaptığını hatırlamak              • REMEMBER TO DO: Yapmayı unutmamak (görev)
• STOP DOING:     Eylemi tamamen bırakmak/sonlandırmak       • STOP TO DO:     Başka şey için duraklamak
• FORGET DOING:   Geçmişte yaptığını unutmak                 • FORGET TO DO:   Yapmayı unutmak
• REGRET DOING:   Yaptığına pişman olmak                     • REGRET TO DO:   Üzülerek bildirmek
• TRY DOING:      Deneyip sonucu görmek (yöntem denemek)     • TRY TO DO:      Yapmak için çabalamak
```

**Kural / Yapı Tablosu:**

| Fiil | + Gerund (-ing) Anlamı | + Infinitive (to + V1) Anlamı |
|:---|:---|:---|
| **Remember** | Geçmişte yapılan bir anıyı hatırlamak (*I remember saving it.*) | Bir görevi yapmayı unutmamak (*Remember to save it.*) |
| **Stop** | Bir alışkanlığı/eylemi tamamen bırakmak (*Stop using PHP.*) | Bir şey yapmak için duraklamak (*Stop to drink water.*) |
| **Forget** | Geçmişte yaşanmış bir olayı unutmak (*I forgot meeting him.*) | Yapması gereken bir şeyi unutmak (*I forgot to lock.*) |
| **Try** | Yeni bir yöntemi/fikri denemek (*Try restarting router.*) | Bir şeyi başarmak için güç harcamak (*Try to fix bug.*) |
| **Regret** | Geçmişte yaptığı bir eyleme pişman olmak (*I regret deleting.*) | Kötü bir haberi üzülerek vermek (*I regret to say...*) |

**Detaylı Anlatım:** A2 seviyesinde fiillerin genellikle ya sadece *Gerund* ya da sadece *Infinitive* aldığını görmüştük. B1 seviyesindeki bu 5 fiil ise her iki yapıyı da alır; ancak **cümleye kattıkları anlam tamamen farklıdır**:

1. **Remember / Forget:**  
   - *Remember to do:* İleriye dönük bir sorumluluğu hatırlamak (*"Remember to sanitize inputs"*).  
   - *Remember doing:* Gözünün önüne geçmişteki bir anının gelmesi (*"I remember compiling this kernel without errors"*).  
2. **Stop:**  
   - *Stop doing:* O eylemi artık yapmamak, kesmek (*"We stopped using monolithic servers"*).  
   - *Stop to do:* Yürürken, çalışırken mola verip başka bir amaca geçmek (*"We stopped to review the logs"*).  
3. **Try:**  
   - *Try to do:* Zor bir işi yapmak için çabalamak (*"I tried to optimize the memory usage"*).  
   - *Try doing:* Alternatif bir çözüm yolu olarak deneme yapmak (*"Try clearing your browser cache"*).

**Canlı Mini Diyalog (Real-Life Scenario):**

> **Junior:** The server connection is still failing. What should I do?  
> **Senior:** **Try restarting** the Docker daemon (Yöntem dene).  
> **Junior:** I already **tried to restart** it, but it threw a permission error (Çabaladım ama olmadı).  
> **Senior:** Ah\! **Remember to run** the command with sudo privileges (Görevi unutma).

**Sık Yapılan Hatalar:**

* ❌ *Hatalı:* Remember backing up the database before the migration.  
  ✔️ *Doğru:* **Remember to back up the database before the migration.** *(Açıklama: İleriye dönük görev hatırlatırken 'remember to do' kullanılır).*  
* ❌ *Hatalı:* We stopped the server to coding in Python.  
  ✔️ *Doğru:* **We stopped coding in Python.** *(Açıklama: Eylemi bırakmak anlamında 'stop doing' kullanılır).*  
* ❌ *Hatalı:* I regret to tell you that I deleted the production table.  
  ✔️ *Doğru:* **I regret deleting the production table.** *(Açıklama: Geçmişte yapılan hatanın pişmanlığında 'regret doing' kullanılır).*

**Genişletilmiş Örnek Cümleler:**

1. 🇬🇧 *Remember to sanitize all user inputs before executing raw SQL queries.* → 🇹🇷 Ham SQL sorgularını çalıştırmadan önce tüm kullanıcı girdilerini temizlemeyi unutmayın (Görev).  
2. 🇬🇧 *I distinctly remember compiling the binary on a Linux machine without any linker errors.* → 🇹🇷 İkili (binary) dosyayı bir Linux makinesinde hiçbir bağlayıcı hatası olmadan derlediğimi net bir şekilde hatırlıyorum (Geçmiş anı).  
3. 🇬🇧 *We stopped using shared hosting servers because our daily traffic increased exponentially.* → 🇹🇷 Günlük trafiğimiz katlanarak arttığı için paylaşımlı barındırma sunucularını kullanmayı bıraktık (Eylemi sonlandırma).  
4. 🇬🇧 *During the long debugging session, we stopped to drink some coffee and discuss the architecture.* → 🇹🇷 Uzun hata ayıklama oturumu sırasında biraz kahve içmek ve mimariyi tartışmak için durakladık (Mola verip başka amaca geçme).  
5. 🇬🇧 *I forgot to push my local commits to the remote repository before leaving the office.* → 🇹🇷 Ofisten ayrılmadan önce yerel commit'lerimi uzak depoya göndermeyi unuttum (Görevi unutma).  
6. 🇬🇧 *I will never forget deploying my first commercial full-stack web application.* → 🇹🇷 İlk ticari tam yığın web uygulamamı yayına aldığım anı asla unutmayacağım (Geçmiş anı).  
7. 🇬🇧 *If the authentication token is rejected, try clearing your browser cookies and local storage.* → 🇹🇷 Kimlik doğrulama belirteci reddedilirse, tarayıcı çerezlerinizi ve yerel depolamanızı temizlemeyi deneyin (Yöntem deneme).  
8. 🇬🇧 *The junior developer tried to resolve the merge conflict, but he needed senior assistance.* → 🇹🇷 Kıdemsiz geliştirici birleştirme çakışmasını çözmeye çalıştı (çabaladı), ancak kıdemli desteğine ihtiyaç duydu.  
9. 🇬🇧 *We regret to inform you that your application for the senior architect position was unsuccessful.* → 🇹🇷 Kıdemli mimar pozisyonu başvurunuzun başarısız olduğunu üzülerek bildiririz (Resmi kötü haber).  
10. 🇬🇧 *I deeply regret committing hardcoded API credentials to the public GitHub repository.* → 🇹🇷 Herkese açık GitHub deposuna sabit kodlanmış API kimlik bilgilerini gönderdiğime (commit ettiğime) derinden pişmanım (Geçmiş pişmanlığı).

## [B1_G10] Phrasal Verbs (Separable vs. Inseparable)

**Kısaca ne işe yarar:** Bir fiilin yanına bir veya iki edat/zarf parçacığı (particle) alarak kendi temel anlamından tamamen farklı, deyimsel ve profesyonel yeni anlamlar kazanmasıyla akıcı İngilizce konuşmak için kullanılır.

**Görsel Şema / Zihin Haritası (Visual Mind-Map):**

```
                ┌──────────────────────────────────────────────┐
                │          PHRASAL VERB AYRIŞTIRMA MATRİSİ     │
                └──────────────────────┬───────────────────────┘
                                       │
        ┌──────────────────────────────┴──────────────────────────────┐
        ▼                                                             ▼
[ AYRILABİLEN (Separable) ]                                  [ AYRILAMAYAN (Inseparable) ]
• Nesne araya GİREBİLİR                                       • Edat ve fiil ASLA ayrılmaz
• Zamir (it/them) gelirse ARAYA GİRMEK ZORUNDADIR!            • Nesne daima edatın arkasında kalır
──────────────────────────────────────────────────            ────────────────────────────────────
✔️ Turn ON the server.                                        ✔️ Look FOR the error.
✔️ Turn the server ON.                                        ❌ Look the error FOR. (Hatalı!)
✔️ Turn IT on. (Zamir araya girer!)
❌ Turn on it. (Hatalı!)
```

**Kural / Yapı Tablosu:**

| Tür | Phrasal Verb | Anlamı | Nesne İsim İse | Nesne Zamir (it/them) İse |
|:---|:---|:---|:---|:---|
| **Ayrılabilen** | `set up` | Kurmak / Yapılandırmak | *Set up the server* / *Set the server up* | *Set it up* (Zorunlu araya girer) |
| **Ayrılabilen** | `turn off / on` | Kapatmak / Açmak | *Turn off the VM* / *Turn the VM off* | *Turn it off* |
| **Ayrılabilen** | `figure out` | Çözmek / Anlamak | *Figure out the bug* / *Figure the bug out* | *Figure it out* |
| **Ayrılabilen** | `back up` | Yedeklemek | *Back up the data* / *Back the data up* | *Back it up* |
| **Ayrılamayan** | `look for` | Aramak | *Look for the log file* | *Look for it* (Ayrılamaz) |
| **Ayrılamayan** | `run into` | Karşılaşmak (Beklenmedik) | *Run into an issue* | *Run into it* |
| **Ayrılamayan** | `deal with` | Başa çıkmak / İlgilenmek | *Deal with high latency* | *Deal with it* |
| **Ayrılamayan** | `come across` | Rastlamak | *Come across a bug* | *Come across it* |

**Detaylı Anlatım:**

1. **Ayrılabilen Phrasal Verbler (Separable):** Eğer nesne normal bir isim ise (*the server, the computer*), edatın arkasına da gelebilir, fiil ile edatın arasına da girebilir:  
   - *"I will set up the environment."* ✔️  
   - *"I will set the environment up."* ✔️  
   - **Kritik Kural:** Eğer nesne bir zamir ise (*it, them, him, her*), edat ile fiilin **arasına girmek zorundadır**:  
   - *"I will set it up."* ✔️ (*"I will set up it"* ❌).  
2. **Ayrılamayan Phrasal Verbler (Inseparable):** Edat ile fiil birbirine yapışıktır; aralarına hiçbir şey giremez:  
   - *"I am looking for my keys."* ✔️ (*"I am looking my keys for"* ❌).

**Canlı Mini Diyalog (Real-Life Scenario):**

> **Lead:** Did you **figure out** why the authentication endpoint is failing?  
> **Developer:** Yes, I **looked into** the logs and **came across** a null pointer error.  
> **Lead:** Can you **fix it up** and **back up** the database before deploying?  
> **Developer:** Sure, I will **back it up** right away and **roll out** the update.

**Sık Yapılan Hatalar:**

* ❌ *Hatalı:* The server crashed, please turn on it again.  
  ✔️ *Doğru:* **The server crashed, please turn it on again.** *(Açıklama: Ayrılabilen fiillerde 'it/them' zamiri ortaya girmek zorundadır).*  
* ❌ *Hatalı:* I am looking my password for.  
  ✔️ *Doğru:* **I am looking for my password.** *(Açıklama: 'Look for' ayrılamayan bir phrasal verb'tür).*  
* ❌ *Hatalı:* We ran an unexpected issue into.  
  ✔️ *Doğru:* **We ran into an unexpected issue.** *(Açıklama: 'Run into' ayrılamaz).*

**Genişletilmiş Örnek Cümleler:**

1. 🇬🇧 *It took our engineering team three hours to figure out the root cause of the memory leak.* → 🇹🇷 Mühendislik ekibimizin bellek sızıntısının kök nedenini çözmesi üç saat sürdü.  
2. 🇬🇧 *Please remember to back up the production database before executing the migration script.* → 🇹🇷 Taşıma betiğini çalıştırmadan önce lütfen canlı veritabanını yedeklemeyi unutmayın.  
3. 🇬🇧 *We need to set up a dedicated virtual machine for continuous integration testing.* → 🇹🇷 Sürekli entegrasyon testleri için özel bir sanal makine kurmamız gerekiyor.  
4. 🇬🇧 *The system architect is currently looking into the network latency discrepancy.* → 🇹🇷 Sistem mimarı şu anda ağ gecikmesi tutarsızlığını incelemektedir.  
5. 🇬🇧 *If you run into any permission errors during installation, run the command with administrator rights.* → 🇹🇷 Kurulum sırasında herhangi bir izin hatasıyla karşılaşırsanız, komutu yönetici haklarıyla çalıştırın.  
6. 🇬🇧 *Our customer support team deals with hundreds of technical inquiries every single day.* → 🇹🇷 Müşteri destek ekibimiz her gün yüzlerce teknik soruyla ilgilenmektedir.  
7. 🇬🇧 *While reviewing the open-source repository, I came across an ingenious sorting algorithm.* → 🇹🇷 Açık kaynaklı depoyu incelerken dahiyane bir sıralama algoritmasına rastladım.  
8. 🇬🇧 *The developer forgot to turn off the expensive GPU cloud instances after testing.* → 🇹🇷 Geliştirici, testten sonra pahalı GPU bulut örneklerini kapatmayı unuttu.  
9. 🇬🇧 *We have to roll back the latest deployment because users are experiencing login failures.* → 🇹🇷 Kullanıcılar giriş hataları yaşadığı için en son dağıtımı geri almak (rollback yapmak) zorundayız.  
10. 🇬🇧 *Can you help me point out the syntax error in this complex SQL query?* → 🇹🇷 Bu karmaşık SQL sorgusundaki sözdizimi hatasını bana göstermeme yardım edebilir misiniz?

## [B1_G11] Question Tags & Indirect / Embedded Questions (isn't it?, could you tell me where...?)

> **Ek B1 Tamamlayıcı Konu:** CEFR B1 düzeyinde profesyonel nezaket, bilgi teyidi ve kibar iş görüşmeleri yapabilmek için teyit soruları (Question Tags) ve dolaylı sorular (Indirect Questions) kritik öneme sahiptir.

**Kısaca ne işe yarar:** Karşı taraftan onay/teyit almak (*"öyle değil mi?"*) ve iş/resmi ortamlarda kaba görünmemek için soruları dolaylı ve kibar bir üslupla (*"Bana ... nerede olduğunu söyleyebilir misiniz?"*) sormak için kullanılır.

**Görsel Şema / Zihin Haritası (Visual Mind-Map):**

```
                ┌──────────────────────────────────────────────┐
                │        QUESTION TAGS (Zıt Kutuplar Kuralı)   │
                └──────────────────────┬───────────────────────┘
                                       │
        ┌──────────────────────────────┴──────────────────────────────┐
        ▼                                                             ▼
[ CÜMLE OLUMLU (+)  ──►  TAG OLUMSUZ (-) ]           [ CÜMLE OLUMSUZ (-) ──►  TAG OLUMLU (+) ]
• "You are a developer, AREN'T YOU?"                  • "You aren't late, ARE YOU?"
• "He wrote this code, DIDN'T HE?"                   • "He didn't deploy, DID HE?"

                ┌──────────────────────────────────────────────┐
                │     INDIRECT QUESTIONS (Düz Cümle Dönüşümü)  │
                └──────────────────────┬───────────────────────┘
                                       │
Direct:   "Where IS the server?" (Kaba / Doğrudan Soru)
Indirect: "Could you tell me WHERE THE SERVER IS?" (Kibar / Düz Cümle Sıralaması!)
```

**Kural / Yapı Tablosu:**

| Yapı Türü | Cümle Kalıbı | Kural | Örnek |
|:---|:---|:---|:---|
| **Question Tag (+/-)** | `(+) Cümle, (-) Tag?` | Cümle olumluysa tag olumsuz olur | *PostgreSQL is scalable, isn't it?* |
| **Question Tag (-/+)** | `(-) Cümle, (+) Tag?` | Cümle olumsuzsa tag olumlu olur | *You don't have access, do you?* |
| **Indirect Wh- Soru** | `Could you tell me + Wh- + Özne + Fiil` | Soru dizilimi düz cümleye döner | *Do you know where the API is hosted?* |
| **Indirect Yes/No** | `Do you know + if/whether + Özne + Fiil` | `if / whether` kullanılır | *Can you tell me if the build passed?* |

**Detaylı Anlatım:**

1. **Question Tags (Teyit Soruları):** Cümlenin yardımcı fiili neyse ters kutbuna çevrilir:  
   - *is → isn't it?*  
   - *can → can't you?*  
   - *went (V2) → didn't you?*  
   - *will → won't they?*  
2. **Indirect Questions (Dolaylı / Kibar Sorular):** *"Where is the station?"* gibi doğrudan sorular resmi ortamlarda kaba veya emir gibi algılanabilir. Bunun yerine kibar bir giriş kalıbı (*Could you tell me...*, *Do you know...*, *I was wondering...*) kullanılır.  
   - **En Önemli Kural:** Giriş kalıbından sonraki kısım **soru yapısından çıkar ve düz cümle (Özne \+ Fiil) dizilimine** döner:  
   - *"Do you know what time the meeting starts?"* (*what time does the meeting start* ❌).

**Canlı Mini Diyalog (Real-Life Scenario):**

> **Visitor:** Excuse me, **could you tell me where the engineering department is**?  
> **Receptionist:** Sure, it is on the third floor. You are Oğuzhan, **aren't you**?  
> **Visitor:** Yes, I am. **Do you know if** the project manager is in her office?  
> **Receptionist:** Yes, she is waiting for you.

**Sık Yapılan Hatalar:**

* ❌ *Hatalı:* Could you tell me where is the database server?  
  ✔️ *Doğru:* **Could you tell me where the database server is?** *(Açıklama: Dolaylı sorularda fiil cümlenin sonuna, öznenin arkasına geçer).*  
* ❌ *Hatalı:* You write clean code, isn't it?  
  ✔️ *Doğru:* **You write clean code, don't you?** *(Açıklama: Geniş zaman eylem fiillerinde 'do/don't' kullanılır).*  
* ❌ *Hatalı:* He didn't fix the bug, didn't he?  
  ✔️ *Doğru:* **He didn't fix the bug, did he?** *(Açıklama: Cümle olumsuz ise tag olumlu olmalıdır).*

**Genişletilmiş Örnek Cümleler:**

1. 🇬🇧 *You are familiar with modern Android development and Jetpack Compose, aren't you?* → 🇹🇷 Modern Android geliştirme ve Jetpack Compose konularına aşinasınız, değil mi?  
2. 🇬🇧 *Could you please tell me where the server configuration files are located?* → 🇹🇷 Sunucu yapılandırma dosyalarının nerede bulunduğunu bana söyleyebilir misiniz?  
3. 🇬🇧 *The automated deployment script finished without any errors, didn't it?* → 🇹🇷 Otomatik dağıtım betiği herhangi bir hata olmadan tamamlandı, değil mi?  
4. 🇬🇧 *Do you happen to know if the client has approved the updated budget proposal?* → 🇹🇷 Müşterinin güncellenmiş bütçe teklifini onaylayıp onaylamadığını biliyor musunuz?  
5. 🇬🇧 *We don't need to restart the entire database cluster for this minor change, do we?* → 🇹🇷 Bu küçük değişiklik için tüm veritabanı kümesini yeniden başlatmamız gerekmiyor, değil mi?  
6. 🇬🇧 *I was wondering whether you could review my open pull request before noon.* → 🇹🇷 Öğleden önce açık çekme isteğimi inceleyip inceleyemeyeceğinizi merak ediyordum.  
7. 🇬🇧 *She has worked as a full-stack engineer before, hasn't she?* → 🇹🇷 O daha önce tam yığın mühendisi olarak çalışmıştı, değil mi?  
8. 🇬🇧 *Can you explain how this machine learning model processes real-time video streams?* → 🇹🇷 Bu makine öğrenmesi modelinin gerçek zamanlı video akışlarını nasıl işlediğini açıklayabilir misiniz?  
9. 🇬🇧 *You will send me the updated API documentation by tomorrow morning, won't you?* → 🇹🇷 Güncellenmiş API dokümantasyonunu yarın sabaha kadar bana göndereceksiniz, değil mi?  
10. 🇬🇧 *Could you let me know what time the technical interview session begins?* → 🇹🇷 Teknik mülakat oturumunun saat kaçta başladığını bana bildirebilir misiniz?

## [B1_G12] Wish & If Only Clauses (Present & Future Regrets / Wishes)

> **Ek B1 Tamamlayıcı Konu:** CEFR B1 seviyesinde şu anki durumdan duyulan memnuniyetsizlikleri, dilekleri ve geleceğe dair değişim arzularını ifade etmek için 'Wish' yapıları temel bir ifade zenginliği sağlar.

**Kısaca ne işe yarar:** Şimdiki zamanda var olan bir durumun farklı olmasını dilemek (*"Keşke ... olsa"*) veya bir başkasının rahatsız edici bir davranışını değiştirmesini arzu etmek için kullanılır.

**Görsel Şema / Zihin Haritası (Visual Mind-Map):**

```
                ┌──────────────────────────────────────────────┐

[ ŞİMDİKİ ZAMAN DİLEĞİ (Present Wish) ]                      [ GELECEK / ŞİKAYET DİLEĞİ (Future/Annoyance) ]
• Şu anki durumun tersini dilemek                             • Bir başkasının davranışını değiştirmesini istemek
• Formül: WISH + PAST SIMPLE (V2 / were)                      • Formül: WISH + WOULD + V1
────────────────────────────────────────                      ───────────────────────────────────────────
"I wish I HAD a faster GPU."                                  "I wish the client WOULD STOP changing scope."
(Şu an hızlı GPU'm yok, keşke olsa!)                          (Müşteri keşke kapsamı değiştirmeyi bıraksa!)
```

**Kural / Yapı Tablosu:**

| Dilek Türü | Zaman Kaydırması (Formül) | Anlamı | Örnek Cümle |
|:---|:---|:---|:---|
| **Şimdiki Durum Dileği** | `Subject + wish + Past Simple (V2)` | Şu an öyle değil, keşke öyle olsa | *I wish I had more RAM on my PC.* |
| **'To Be' Durumu** | `Subject + wish + were (tüm özneler)` | Keşke ... olsaydım / olsa | *I wish the server were faster.* |
| **Yetenek Dileği** | `Subject + wish + could + V1` | Keşke yapabilsem | *I wish I could speak fluent German.* |
| **Şikayet / Gelecek** | `Subject + wish + would + V1` | Keşke (bir başkası) ... yapsa/bıraksa | *I wish the server wouldn't crash.* |
| **If Only (Vurgulu)** | `If only + Past Simple / would` | "Ah keşke..." (Daha dramatik/güçlü) | *If only we had more time!* |

**Detaylı Anlatım:** *Wish* ve *If only* cümlelerinde en önemli zihinsel kural: **Dilek gerçekleşmeyen bir şeyi arzuladığı için zaman daima bir adım geçmişe kayar (Past tense kullanılır).**

1. **Şimdiki Zaman İçin Dilekler (*Wish \+ Past Simple*):**  
   - Gerçek durum: *"I don't know Python."* (Python bilmiyorum).  
   - Dilek: *"I wish I knew Python."* (Keşke Python bilseydim).  
   - 'To be' için resmi dilde tüm öznelerde **were** kullanılır: *"I wish I were in Berlin right now."*  
2. **Şikayetler ve Başkalarından Beklentiler (*Wish \+ Would*):** Karşı tarafın yaptığı ve bizi rahatsız eden bir eylemi değiştirmesini istediğimizde kullanılır:  
   - *"I wish you would write comments in your code."* (Keşke kodunda yorum satırları yazsan).  
   - **Kural:** Kendi kendimiz için *I wish I would* **kullanılmaz**; onun yerine *I wish I could* kullanılır.

**Canlı Mini Diyalog (Real-Life Scenario):**

> **Junior:** The build process takes fifteen minutes every single time.  
> **Senior:** I **wish our CI pipeline were** faster, but the test suite is very extensive.  
> **Junior:** **If only we had** dedicated build servers\!  
> **Senior:** I **wish the management would approve** our cloud budget request soon.

**Sık Yapılan Hatalar:**

* ❌ *Hatalı:* I wish I have more free time to study AI.  
  ✔️ *Doğru:* **I wish I had more free time to study AI.** *(Açıklama: Şimdiki zaman dileklerinde fiil Past Simple (had) olur).*  
* ❌ *Hatalı:* I wish I would speak English fluently.  
  ✔️ *Doğru:* **I wish I could speak English fluently.** *(Açıklama: Kendi yetenek dileklerimizde 'would' değil, 'could' kullanılır).*  
* ❌ *Hatalı:* I wish the weather will be sunny tomorrow.  
  ✔️ *Doğru:* **I hope the weather will be sunny tomorrow.** veya **I wish the weather were sunny.** *(Açıklama: Geleceğe dair gerçekçi umutlarda 'hope', gerçek dışı arzularda 'wish \+ would' kullanılır).*

**Genişletilmiş Örnek Cümleler:**

1. 🇬🇧 *I wish I had more high-performance GPU clusters to train neural networks locally.* → 🇹🇷 Yapay sinir ağlarını yerel olarak eğitmek için keşke daha fazla yüksek performanslı GPU kümem olsaydı.  
2. 🇬🇧 *I wish our development team were located in the same physical office space.* → 🇹🇷 Keşke geliştirme ekibimiz aynı fiziksel ofis alanında bulunuyor olsaydı.  
3. 🇬🇧 *If only we had comprehensive documentation for this legacy backend codebase\!* → 🇹🇷 Ah keşke bu eski arka uç kod tabanı için kapsamlı dokümantasyonumuz olsaydı\!  
4. 🇬🇧 *I wish the client would stop changing the product requirements during the sprint.* → 🇹🇷 Keşke müşteri sprint sırasında ürün gereksinimlerini değiştirmeyi bıraksa.  
5. 🇬🇧 *She wishes she could attend the upcoming international software conference in San Francisco.* → 🇹🇷 San Francisco'daki yaklaşan uluslararası yazılım konferansına katılabilmeyi diliyor (keşke katılabilse).  
6. 🇬🇧 *I wish our database queries didn't take so long to execute under heavy load.* → 🇹🇷 Keşke veritabanı sorgularımızın yoğun yük altında çalışması bu kadar uzun sürmese.  
7. 🇬🇧 *If only we were aware of the security vulnerability before the public release\!* → 🇹🇷 Ah keşke genel kullanıma sunulmadan önce güvenlik açığından haberdar olsaydık\!  
8. 🇬🇧 *The developers wish management would invest in automated integration testing tools.* → 🇹🇷 Geliştiriciler, yönetimin otomatik entegrasyon testi araçlarına yatırım yapmasını diliyor.  
9. 🇬🇧 *I wish I didn't have to debug legacy PHP code on the weekend.* → 🇹🇷 Keşke hafta sonu eski PHP kodundaki hataları ayıklamak zorunda kalmasaydım.  
10. 🇬🇧 *Do you wish you lived in a different time zone for easier remote work with international clients?* → 🇹🇷 Uluslararası müşterilerle daha kolay uzaktan çalışmak için farklı bir saat diliminde yaşamayı diler miydin?
